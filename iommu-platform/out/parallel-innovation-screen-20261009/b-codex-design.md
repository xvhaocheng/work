# B 席：译址准备与真实写承诺联合调度的贡献筛选

2026-10-09。Codex 亲自设计、推导、核关键源码和原论文；没有派子 agent 或 DeepSeek。本席只写本文件，没有改生产 RTL/Linux/test、没有构建、仿真或上板。本文的数字是手算模型，不是实验数据。

## 判定

**本轮不把 B 送进 RTL。** 最强新草案是“由不可撤写顺序和未消费字节推导译址的服务机会，再联合选择准备与提交”。它能区别单纯 PTW 最短任务优先，但在下面明确合同内，被一个具体、很小的普通方法完全复现：**先准备当前写顺序中最早缺译址的 copy，已经准备好的 copy 进入 ready 队列；数据仍走准确 owner 准入。** 本轮已经给出等效推导，不是仅因它可以叫 EDF 就否定。

如果后续发现真实平台中，译址成本/可消费字节因共享 DDR 的服务顺序而相互改变，且新反馈规则在同信息、总状态和正确协议下提供这个普通方法没有的决定或保证，就可以重新立 B 的架构贡献；目前没有这种正向见证。不能把普通 prefetch、ready queue、物理旁路、最短 PTW 或“识别阻塞者”单独作为新规则。也不需要否定所有想象出来的程序。

## 1. 仅保留的一条草案：由写承诺导出准备机会

在任何新的**虚拟 AW 首次 VALID 之前**，对每个可见正常 copy 的下一片段区分：

- `committed`：其虚拟/物理 W 先后已被协议承诺；该顺序和已持有 VALID 不可重排。
- `prepared`：本片段 own-context READ、WRITE 权限及 PA/属性已经成功，且仍处于当前有效世代；仅缓存有 entry 不代表授权成立。
- `support`：本片段已有返回数据，或准确对应的源 R 获得独立可排空合同；不能只看瞬时 WREADY。
- `remaining`：前驱已经承诺但尚未被实际 W 消费的逻辑字节数，不用 IOTLB miss 数替代。

草案的动作是：根据固定写前驱的 `remaining` 估计本片段最早真正可消费的时刻；以预测的 copy 完成代价比较下一个译址准备对象。**准备动作不取得 W 所有权；真实 AW 仍需自己的有效权限和准确数据支持。** 在准备阶段允许丢弃 hint，实际 AR/AW 的首次 VALID、地址、长度、ID 和返回关联保持不可撤。没有权限的目的页绝不能用“之后会译好”代替许可。

最小接口/资源：已有 copy 序号、src/dst/有效逻辑区间及 parent 序列；虚拟/物理 W 队首序号、实际消费边界；当前 own-context 译址成功/错误/失效信息；一个每-flow 的准备对象标记与年龄；可选 PTW 成本估计。需要真正的副作用受限准备接口，生产 TC 现在没有一个开关即可打开的该接口。已有层次观测 wire 不能算免费接口成本；新增状态/比较逻辑没有综合。

公平与进度合同：老的 R/W/B 债务一直获准排空；年龄上限只改变**尚未开始**的准备/仲裁选择，不能撤已在途 walk/VALID；任一有效准备请求在公平、有限服务假设下最终服务。译址失败必须使用实际 fault/error 合同，本平台 iDMA 的 NO_ERROR_HANDLING 不能凭这条规则变成可恢复 fault。动态估计只用于性能选择，不用于授权、安全或死锁证明。

它提供的正向能力假设是“翻译完成的时机和真正消费机会一致，少做用不上的准备，避免提前翻译后仍占住 W 顺序”。下面先检查这个假设有没有额外动作，而非直接实现。

## 2. 唯一最小判别场景：固定 W 顺序下提前准备谁

这是一个刻意有利于联合准备的两阶段简模，且已足够筛掉这个草案的最初贡献主张：

- 时刻 0，既有 V 的写数据还能独立服务 32 个单位，故后续数据阶段最早在 `r=32` 空闲。
- 虚拟与物理 W 已一致地承诺后续顺序 **A 然后 B**；A/B 没有跨 copy 地址依赖。这里的顺序来自真实协议承诺，不是假造为了获胜的强制顺序。
- A 的其余译址准备耗时 `a=48`，其数据阶段 `x=64`；B 的准备 `b=8`，数据 `y=8`。自己的目的写授权已获确认，缺的可以是源 READ 准备；没有未授权数据访问。
- 一个非抢占译址服务者；准备成本不随顺序改变；两个准备结果可安全保留；数据阶段一次服务一个 copy；普通 owner 门保证小 FIFO 的正确直通。准备与既有数据在这个理想模型中可以重叠。
- 这不是当前行为 DDR/MIG 的准确模型；忽略共享 R 服务竞争、缓存替换、地址流水和 B 延迟。**若在这更简单的有利模型里没有独有决定，就无须为它先修真实夹具。**

| 译址选择 | 译址轨迹 | A 数据/完成 | B 数据/完成 | A/B 完成均值 |
|---|---|---|---|---:|
| 普通 PTW SJF，先 B | B 0–8，A 8–56 | 56–120，120 | 120–128，128 | 124 |
| 草案联合机会，先 A | A 0–48，B 48–56 | 48–112，112 | 112–120，120 | 116 |
| **普通下一 W-owner lookahead，先 A** | **A 0–48，B 48–56** | **48–112，112** | **112–120，120** | **116** |

草案相对 SJF 的 8 单位收益不是独有贡献，因为普通具体方法同一准备顺序、同一两个结果槽、同一数据路径就得到完全一样的轨迹。本表没有捏造额外缓存或 payload 给普通方法，也没有要求它采用本提案的复杂评分器。

### 等效不是偶然：两任务交换推导

对上述合同，令准备耗时 `a,b≥0`、数据耗时 `x,y≥0`、既有数据释放时刻 `r≥0`，数据顺序固定 A→B。

先准备 A：

```
C_A^AB = max(r,a) + x
C_B^AB = max(C_A^AB,a+b) + y
```

先准备 B：

```
C_A^BA = max(r,a+b) + x
C_B^BA = C_A^BA + y
```

由单调性 `C_A^AB ≤ C_A^BA`；又因为 `C_A^BA ≥ a+b`，有 `C_B^AB ≤ C_B^BA`。所以先准备较早 W-owner 对两个 copy 的完成都不差，完成均值和 makespan 也不差。复杂 slack 估计或两方案打分在这个合同内无需增加能力。

**适用限制很具体**：非抢占 whole-pair 准备、单准备服务者、固定 W 顺序、足够保存两个准备结果、准备耗时与顺序独立、准备/数据服务不相互改变。不是四 DMA/任意 page-walk/所有调度的最优定理。两份证书的资源不足、PWC/DDR 的顺序相关成本、尚未承诺 W 的可重排性，都可以打破这些前提；它们是另一个问题，不能暗中换合同后沿用本推导。

如果完全允许未提交 copy 自由重排，并把所有准备合成固定耗时的第一阶段、搬运合成第二阶段，就映射到经典 two-stage flow shop。这个**简化映射由本席推导**；它不证明完整 IOMMU/AXI copy 等价于 Johnson 模型，也不否定有额外真实约束的架构论文。Johnson 1954 原论文的已知服务时间、每阶段一次一任务、第一阶段后第二阶段与 makespan 目标已明列于[出版商原文摘要](https://onlinelibrary.wiley.com/doi/pdf/10.1002/nav.3800010110)。本轮取得摘要，未取得全文，不能声称已通读。

## 4. 平台源核与不能省掉的协议位置

- `cva6/vendor/pulp-platform/axi/src/axi_mux.sv:207–239`：新的 AW 仲裁决定在首次 offer 时推动 W-order FIFO，并在下游 stall 后锁住 VALID。要改写顺序必须在这里**之前**完成准备/选择；晚阻塞后级物理 AW 不能恢复已承诺虚拟顺序。`277–289` 根据 FIFO owner 路由 W 并在实际 WLAST 弹出。
- `cva6/corev_apu/riscv-iommu/rtl/transaction_controller/rv_iommu_trans_ctl_wrap.sv:620–730`：IDLE 优先 AW，译址和物理地址接受是 TC 的服务路径；它没有自然从 W 字节消费边界导出的准备机会接口。此前 §40 已确认其 COMPLETE 在物理 AR/AW ready 后回 IDLE，并不把全 copy 完成锁传给 CQ，不能假造这项占槽来获得创新。
- `tests/nonblock_completion_pool_late.sv:142–171`：现普通 virtual-W-head 准入已使用 matching prepared AW 和准确 src/dst 逻辑偏移，复杂物理前缀扫描关闭时仍可安全服务当前 owner。不要把这个已存在能力从普通基线删除。
- `tests/nonblock_actual_dma_top.sv:638–661`：copy 和 W 顺序来自实际 iDMA 与 mux，但当前为测试侧层次连线。生产接口必须定义 normal copy、job/parent 序号、有效字节、世代和故障，不可说“本来有变量”就免费获得。
- `cva6/corev_apu/iDMA/src/frontends/register_64bit/idma_reg64_frontend.sv:366–373` 和 `src/idma_legalizer.sv:193–210`：CONF bit0 控制 R/W 分段解耦；旧 PN 的 CONF0 对齐形状不能拿新的独立分段或晚到共享源解释。

## 5. 停止条件与真正能重开 B 的问题

**本轮停止**：不实现 slack scorer，不改夹具，不为表中 8 单位收益编 RTL；普通 next-owner 方法已同决定同资源同效。同样不保留最小分片的另一套名字——在静态准确 W-cover 下，它退化为既有 owner 直通/固定安全分片，且与本席任务的译址调度角度无独立差异。

B 的真实未解约束是：**共享 DDR 的一个服务决定，会同时改变 walk 完成时间和已承诺写的实际排空时间；“准备耗时”和“消费截止点”不再是独立输入。** 此时需要证明某个具体 PTE/数据选择降低联合完成代价，而不是先定义固定 deadline 再套 EDF。该问题仍属于翻译与搬运干扰主线，区别于晚到 shared-read 的 A 和替换局部性的 C。

最小重开条件为：用已有实际轨迹或很小的 timed 模型给出一个合法状态，在保留 held VALID、同 ID 顺序和原总容量下，ordinary next-owner lookahead/已有 MASK 式翻译优先与新规则选择不同；列清新规则可见的信息和依赖，证明两路综合完成收益/可检查保证；并确认不只是已测 DS 优先或普通 ready queue。**如果这个边界产生独有机制/保证和可信成本结果，就可以称架构创新；因为本轮还没有该见证，就不能把当前固定-deadline 草案作为独立算法。**

可以先把 B 降为主线的强工程 baseline 与模型约束提供者，把当前 RTL 预算给在本轮筛选中已有正向差异的 A/C 候选。并行探索的价值是这里在推导层及时止损，而不是三席都各修一套夹具。
