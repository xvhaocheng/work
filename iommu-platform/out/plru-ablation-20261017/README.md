# IOTLB 替换策略消融（2026-10-17）

两路真实 iDMA 各做 64 次 4KiB COPY；时间包含冷前缀、配置、补发、完成发现及 quiet，单位为行为 DDR 模型的 **RTL 仿真时钟步**。P＝两设备分配 2/14 个条目；PN＝P 加命中提前旁路；R＝设备 A 循环使用的目的页数。V0 为原策略；V1 将 mask 下的树近均衡重排，保留原触碰/填充语义（14 叶仍有 3/4 子树）；V2 为精确 LRU，含空项优先、填充成为最近使用。[变体定义](variants/README.md)

1. **机制确认。** R8 的 39 次 walk 是两设备合计：A 37 次、另一设备 2 次。直接追踪确认 A 源常驻 way8，30 次有效逐出全在 way2/3，7 个允许条目始终空闲；目的页 0–7 的 walk 为 `[8,1,8,1,8,1,8,1]`。V1 变为 `[8,1,1,1,8,1,1,1]`，仍有 PLRU 热源偏置；V2 全部为 1。[victim 记录](analysis/victims/)

2. **修正效果。** 每格为「两设备总 walk / 完整完成时间」。

| 组织 | 目的页数 | V0 | V1 | V2 |
|---|---|---:|---:|---:|
| P | R1 | 4 / 76,331 | 4 / 76,331 | 4 / 76,331 |
| P | R8 | 39 / 90,290 | 25 / 84,581 | 11 / 79,059 |
| P | R16 | 67 / 101,334 | 67 / 101,334 | 67 / 101,334 |
| PN | R1 | 4 / 76,869 | 4 / 76,869 | 4 / 76,869 |
| PN | R8 | 39 / 106,570 | 25 / 94,481 | 11 / 82,733 |
| PN | R16 | 67 / 130,104 | 67 / 130,104 | 67 / 130,104 |

3. **端到端影响。** R8 的 V2 相对 V0，P/PN 完整时间分别减少 **12.44% / 22.37%**；R1/R16 不变。最后完成设备的「源数据收齐→最后写响应」缩短 20,327 / 43,530 步，但「后端接受→首个源读返回」增加 9,096 / 19,651 步，净减少 11,231 / 23,837 步。收益主要体现为写腿等待下降，不能把重叠的翻译、PTW 和访存时间相加。[完整阶段与逐设备/逐页统计](analysis/findings.md)

4. **普适性。** 所核 CVA6 及上游当前主分支均无这项 way mask，尚无第二个实现复现同款偏置；普通 PLRU 的访问次序局限仍可能共有。Linux 分配器允许相邻/复用页号，但页号奇偶不决定 way；现有 Linux 日志不足以确认流式 map/unmap 触发该现象。[源码、行号与不确定性](generality/README.md)
