# §71 Codex positive design before execution: local online repair binding

Question: can the asynchronous independently authorized late-join engine select its own route using past source service, rather than an external DDR-period oracle? §70 establishes opposite preferred modes. Traffic savings alone do not prove innovation.

Observation is local and causal: while phase0 has an accepted physical V READ, after that child's first real R handshake, count (M) cycles eligible for R but no RVALID, (C) cycles RVALID but not eligible, and (H) real R handshakes. Exclude initial per-child latency; this avoids treating fixed request latency as a bandwidth sample. Sixteen-bit saturating counters; no new payload. Counters freeze on start_cutover, before first A repair AR. Successful independent READ and full WRITE recipes and equal immutable PA/normal attributes remain prerequisites. No testbench knob, future completion, A write latency or interval value is an input to the rule.

Rule0 is a deliberately strong simple comparison: share if H>=8 and M>C, otherwise independent. Rule1 is an explicit geometric cost hypothesis: share if H>=8 and (256-E)*M > (rV-rA)*(C+H), otherwise independent. E is the actual old irrevocable physical endpoint; rV/rA are actual delivered cursors at binding. M/H approximates externally missing service per beat. (C+H)/H estimates local consumer service cost; rV-rA is the lag that must be repaired. This is a heuristic, not a latency bound or proof of optimum. Rule1 must beat or explain a difference from rule0 to claim geometric information matters.

One registered choice is bound on start_cutover. It stays immutable through data-debt closure, old-tail/prefix repair and shared suffix / independent continuation. All read routing and NEW write clipping consult the same choice. All existing firstVALID AR/AW/W/R and B debts stay intact. An assertion checks no choice changes after binding. A missing/short sample conservatively selects independent; E256 independently completes without effective sharing.

Acceptance: complete 2048-byte copies and 256 target W each; strict actual R formula uses bound route (shared E+256, independent512), not measured R to decide expectation; terminal report includes decision, H/M/C, geometry/rule; selected fixed route should exactly reproduce the corresponding §70 CSV and old metrics. Exercise both route choices, geometry and DDR/backpressure stress; keep failures. Behavioral DDR only, no synthesis/board/production modifications.

Novelty target is a bounded-payload admission contract for asynchronous independently translated copies with irrevocable requests, plus causal route binding. Adaptive multicast or a threshold alone is old. If prior work covers the same permission/debt contract and online choice, this cannot be claimed independently; if the contract differs and avoids a demonstrated correctness/latency failure with fair baselines, it can support a mechanism contribution. Independent literature coverage and broader workload/cost evidence are required before a paper claim.
