# stage107 平台大页、准备与单 DMA 合并约束（源码核查）

结论：2MiB IOVA 叶和普通单设备两套 buffer 提交不应因现实验 helper 的限制而被排除。现存 Linux 配置下，整块 10MiB 的 FORCE_CONTIGUOUS 通用分配路线有明确 allocator 上限；强普通替代是每槽五个独立 order9（2MiB）物理 extent，四槽二十块，映射为连续 IOVA。是否能取得二十块、准备/缓存/清理花多久、任务是否授权一个 DID 访问双方 buffer，均没有本轮运行测量。源码可达性、现存构建配置和正在运行的板镜像必须分开。

本席全由 Codex 直接核关键源码并写证据；未调用 DeepSeek/Claude，未构建、未运行 DUT、未连接板、未修改生产源。完整 file:line、源 SHA256 和必要原文保存在 [constraint-evidence.json](constraint-evidence.json)。未重跑 stage106 矩阵。硬件 DID/burst/buffer 资源由 root 独立核查，不用当前 helper 或本地旧 config 代替实板证明。

## 两条调用链

1. DT iommus/DID → OF fwspec → RISC-V endpoint/group/domain/attach → `probe_finalize` 安装 IOMMU DMA ops。当前实验 `idma_stream_prepare` → `dma_alloc_attrs(FORCE_CONTIGUOUS)` → CMA/buddy → DMA API 自动映射；之后再建按 4KiB 的手工别名，descriptor 用这个别名。普通 SG 替代可由多个 order9 extent 经 `dma_map_sg`/`iommu_map_sg` 建连续 IOVA，叶页大小由 PA/IOVA 对齐与物理连续 run 决定。
2. `open` → file 持 `idma_device`（无每进程 domain）→ ioctl → 全局实验 mutex → 内核自分配 stream → SRC/DST/LEN → NEXT_ID → DONE → 双方 drain → FENCE.I/verify → unmap/free。当前 platform 非 PCI endpoint 不启用 PASID，ABI 不接受每 descriptor DID/PASID 或外部 buffer handle。

## 完整成本口径

- 物理存储：四个逻辑 10MiB 槽 = 40MiB 载荷存储；二十个 2MiB 块无整槽连续要求。stage106 的 48MiB host backing 是原模型预算，不能由这里 40MiB 载荷数替代。页表、SG/extent 元数据、IOVA reservation、失败回滚和 padding 所有权另记。20次 allocation/20次显式 extent map 或4次 SG API map 只是代码结构推导，不是实测。
- CPU 准备：申请/潜在 reclaim-compaction，zero/init，真实 tensor 加载或复制，SG 元数据，IOVA 分配，页表分配/写入，同步 IOTLB/IOFENCE，CPU→DMA cache 交接。现 helper 的同 PA 自动映射加手工别名可能增加成本，普通基线可选统一 mapping 路线，不应被迫继承实验冗余。
- 完成与回收：每任务首包、最终完成、公平性取舍，双 buffer 排空，DMA→CPU cache 交接，权限 revoke/IOTLB 同步，unmap/free，无法排空时的隔离/保留。`victim_elapsed_ns` 在 setup 后开始；`drain_ns` 不能覆盖全部 cleanup。
- 提前准备/重用合法性：地址与权限已知、数据 ready、实际 owner 允许、buffer 持续有效、消费完成后才能回收；冷启动与稳态分别计，不能从 host 元数据 init 推出板端成本，更不能人为 ready0 后宣称真实应用自然同时就绪。

stage106 模拟 source-only-read 且无额外 alias；当前 Linux helper 的 source 是 RW，且保留自动 DMA 映射和手工别名。未来 adapter 如声称对象只读或隔离，须检查所有映射及撤销成本；普通性能判别只采用工作流真实要求，不凭空追加安全合同。

单 DMA 合并的约束应写成条件：如果同一可信 owner/broker 已授权该 DID 访问双方数据且控制 descriptors，那么两组 buffer 可普通提交；如果必须保留互不信任任务各自 device-domain 权限，原 DID 的 IOVA 不能直接带到合并 DID，需合法授权/重映射或保留独立域，并计入 drain、revoke 和 setup 成本。现全局 mutex 与内核测试 buffer 不能证明多租户隔离。
