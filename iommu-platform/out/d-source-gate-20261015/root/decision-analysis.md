# D下一来源关口：决策价值、状态来源与跨任务合同

2026-10-15。root分析；复用首批六日志，不重跑任何实验。本页的决策分析是筛选工具，不认领新算法或已成立论文贡献。

## 1. 已有负结果的准确范围

首批三个具名条件的`PN−P`完整COPY向量为`(0,0,0)`、`(3689,3689,3691)`、`(0,0,0)`，向量依次是`(T_V,T_A,T_return)`。在这些已记录条件上，只要评价函数随三项完成时间单调不减，固定P就不劣于PN。因此，限于该记录集合，额外观测不能改善这三项COPY时间的最优动作选择；再付正的观测成本也不能凭空产生选择收益。

这不是所有工作负载的支配定理，也不涉及未测的应用配置/预热/consumer/free费用。没有统计重复或新测量，不能将这些确定记录外推为总体概率、置信区间或真实应用最优。此前的E3局部等待和PN板测不加入这一集合。

## 2. 确定性不是否定D的理由，缺少状态来源才是本关问题

M0登记固定映射、64/64 COPY、gap0、warm256、延迟31、CPUoff、head-serial DDR、av与三个start delay为0。代码先setup_memory/reset，再按固定规则预热并排空；每case是独立闭环。[登记](../../workflow-g0-m0-20261010/baseline-register.json)及[本轮源码核查](../mechanism/mechanism.md)区分实际登记和代码支持的其他参数。

这仍可能在P与PN下产生不同的内部时序；那些是动作导致的结果，不能反过来当作两个动作前不同的外生状态。A页环和服务配置等变化已经属于O0，不能隐藏它们来制造不可辨识。当前合同里没有取得另一个有自然来源、同O0但会改变动作优劣的服务/就绪状态。

确定性系统可以在不同合法输入或历史下产生选择反转，故不由“确定性”推出D不可能。当前裁决只限制：继续重复同一登记case，或任意调起始相位，不能替代所需来源证据。

## 3. N局部放行不等于COPY收益

N在另一bank的S1-only walk窗口启动probe，检查真实DC/leaf、4KiB权限、输入稳定、失效与MSI条件后才握手；响应还须经过单响应端口、bank的COMPLETE和下游协议接受。probe开始后，接受时不再要求walk窗口持续，故`fast_accept`也不能一概当作发生在剩余walk等待之内。源码位置、参数和原文见[机制证据](../mechanism/sources.json)。

完整获益至少需要：合格请求及时到达；早翻译实际推进payload；推进落在完整目标关键路径；由新payload引发的PTE/后台排队及末尾费用没有抵消它。当前head-serial DDR会让早到长payload改变后续PTE服务顺序，这是具体代价链，但不足以证明所有合法交错下PN都更慢。不能将可重叠局部周期简单相加或相减成净收益。

## 4. quiet下一任务选择还需要跨边界的预测依据

板端配置quiet覆盖相应IOMMU外口、观测DMA、job和launch状态；成功配置会清IOTLB valid及PLRU。它没有“整个CPU/其他master停止”“DDR内部队列、行或refresh状态已清零”的证明。M0的check_quiet则另检查模型CPU quiet及三个C++队列为空，且每案此前有完整reset；两个quiet合同不同。

如果新观测Z来自上一任务，而动作作用于下一任务，至少要有一项源支持的关系在quiet/config/clear/warm之后仍保留。若下一任务相关服务态U在给定O0后与Z无关，则Z不能改善下一任务的条件动作判断。若存在持续关系，也仍须验证其稳定性、过期风险和取得成本。这个条件不能靠拼接独立重置case满足。

决策价值可用已有方法定义为：取得Z前的最小条件期望损失，减去取得Z后的最小条件期望损失，再扣其全部增量成本。这里的损失应来自合法动作下完整闭环结果及后台约束；计数共现本身不是损失。普通同信息规则和完整付费试选同样参与比较。

## 5. 保留最强合理后继：由设备完成驱动的自然供给

SPDK的真实回调链可以说明`completion→task_complete→submit_single_io`以及常驻task/buffer复用。不改host IOVA的LBA/设备服务变化，仍可能改变供给时机；不能因IOVA不变就排除其时序研究价值。更强的条件版本是：保持buffer、已知LBA、队列和映射信息公平可见，核实未公开设备服务状态怎样影响completion、重提交和共享服务相遇，以及哪些状态能跨quiet边界持续。

但当前没有该服务状态、实际共享部署、持续性或完整反号结果。M0又没有NVMe命令/设备完成与源就绪的反馈链；仅把一个固定间隔塞入gap不能忠实表示它。此方向因此保留为有源调用链的重设计候选，不能冒称已取得同O0状态对或已获准扩大模型。[来源卡](../sources/source-cards.md)保留实际源码、已知信息和全部缺项。

若以后形成此合同，应在每个动作下重算闭环：DMA/设备完成影响重提交，重提交再影响后续竞争。不能把一个模式下录下的到达时间固定重放为另一模式的实际程序行为。确需开放输入重放时，应明确它只是规定输入实验，其结论范围随之收窄。

## 6. 本关准入规则

允许有来源的条件预测进入小模型判别，**不要求建模前先测出完整反号结果**；否则会把研究关口变成循环要求。准入前必须已有真实事件/调用链、可变状态的源与身份、共同目标/O0/合法动作、如何形成相邻相反预测，以及最小模型能忠实表达这些因果边。模型随后检验符号，失败可以结束该版本。

当前候选缺的是实际共享与状态来源/模型接口匹配，不是尚未先验保证收益。因此本轮不启动模型、不放宽guard、不扩大gap/压力矩阵；也不否决所有D或因为I缺证而自动退回A。后继先补一份具体部署/服务态与回调就绪的联合材料，再决定是否值得建立明确标注的新合同；旧M0继续用于守恒与机制校准。
