# §33 Codex 设计、关键审查与创新立项判断

## 结论

候选 I 已实现到可判别，而非仍停在规格：固定与动态均保留原逻辑源 AR，动态按真实双写序的连续已准备前缀定子片。六次真实两 iDMA 仿真均完成；动态少 9 个物理源 AR，但没有稳定的双方时间收益或总成本优势。当前不批准“动态最长前缀”作为独立论文主贡献。这个判断是本候选的立项判断，不是“世界上一定已有完全同式规则”的证明，也不否定联合问题的研究价值。

## Codex 独立设计与接口审查

1. 插入在完整 completion AR 译址成功之后、物理互连前。原 parent 接受一次；子片不再进入 IOMMU 输入。真实虚拟 source AR 的握手记录源相对 descriptor 偏移，用每流有序队列将这个偏移关联到物理 parent；不以硬编码 PA 反推 dst，不使用瞬时 WREADY 当可消费证明。
2. 两流各 8 parent，每流仅处理最老 parent；未完成的 parent 可暂停，让另一 ID 服务。只有一个物理 child 在途，无新增 R payload 存储。同 ID 顺序、原 ID、原父 RLAST 保持，子 RLAST 仅解除物理占用；原父 RLAST 只在该父全部拍交付时给出。
3. 虚拟 AW 用真实 axi_mux 的 first-offer enqueue 记录；物理 AW 以 completion 接受握手记录；两侧独立环包含 owner 和每流 sequence。根据已经消费的虚拟 W 拍数计算真实 dst 偏移。只选择两环对应、目的偏移连续且 owner 相同的已接受物理 AW 前缀。不能从虚拟队列推断下一物理 owner。
4. C 为这条前缀剩余拍数，L 为当前最老 parent 剩余拍数。固定长度 min(C,L,128)，动态 min(C,L)。后者本例仅出现 128/256 拍，包含跨相邻同 owner W 段的合并。首次外部 VALID 来自 child_q/offered_q，直到 READY 不变。正在返回的 child 不改变长度或抢占 RVALID。
5. 系统旧 flat completion AR 丢弃 cache/lock/qos/region；本 out 复制系统改用真实 i_dma.i_sys.comp_req.ar 全结构，发往互连同样全结构。当前层仍是已有测试 banked_top，其输入已存在的扁平化不因这个改动自动修正。运行 CONF1/cache0/lock0/INCR/size3，原 parent 256 拍不跨4KiB，子128/256拍；符合 Arm AXI4 长度大于16的 Non-modifiable INCR 可拆规则。没有通过伪改 cache 属性放宽合法性。
6. 不支持任意端点、短不可改写事务、exclusive/atomic、映射变化、fault 或 cancel。SV 对超出范围、ring/sequence/child R错误直接 fatal，这是有界研究夹具，不是生产错误处理。两流8槽是保守配置，未声称最小槽数或无条件通用无死锁定理。
7. 保留原 S、实际两DMA四输入mux、同bank重分类、DS50/50、串行行为DDR，原诊断强制反序、AW交错、CPU、batch、warm、gate均关；沿用 out C0提前写额度修正。生产 C0 尚未改，不能直接上 BIT。原76生产SV哈希与§32相同。

## 成本与强普通覆盖

配置的iDMA数据FIFO是两路48B；新增模块声明的非统计状态5962bits，另160bits观测计数。这是按声明宽度的账本，含部分只为有效范围校验而使用的状态，未综合、未计算其被优化后的 FF/LUT/BRAM，也不含公共TC FIFO/cuts/其它既有状态。不能说全部硬件仅48B。

固定与动态共用相同原型槽和声明状态；固定规则仍共用完整前缀扫描逻辑，独立固定综合实现可缩减，不应宣称动态“同总面积”或比固定更省。它们都已经有原逻辑请求保留与进度，动态没有独有译址次数减少、死锁解除或payload容量降低。

## 前作核查与裁决边界

- AXI-REALM2025 §III-A1/A2：可配透明片长、元数据及原RLAST恢复、完整写片缓存后发AW是已明确组件；原文不能推出已做本例跨IOMMU双写序前缀决策。
- Arm DMA350 §4.3.4、§5.8.1（手册22/87页）：整读空间与整写数据条件是强普通破环方法，但不能声称它就是此postTL源调度。PDF formfeed导致LF-nl与bridge splitlines行号不同，worker原行号在bridge约定中有效；Codex的初始“引用错误”指控撤回，改用章节页码及两种编号说明。
- Preemptive VC2026 §I/III：DMA读写依赖环与通用分流/信用/抢占已有；不能把观察到依赖环本身声称新领域。
- TI2025 Adaptive Burst技术披露涉及用FIRST/LAST/REQUEST可终止或延长已有传输，接口允许忽略BYTECNT；与保持已发AXI ARLEN不可改变的本实现不同。动态可配、延长合并本身不是新贡献，但该披露不是已核同式AXI实现。

可辨别的新增选择：本实现9次允许跨相邻同owner写段读完整2KiB parent；固定每次最多1KiB。所核前作没有被证明完全覆盖这一联合判据，亦没有世界首创的证据。当前立项不通过的理由是：相对已保留译址与进度的强固定方法，只减少请求数，时间效果不稳定、无成本优势及通用进度证明。低收益不是“已有工作”的逻辑证明，工程成败也不能替代文献创新审定。

## 主线收敛

保留固定后译址分片作为强基线；停止把“最长已准备前缀”继续包装成主创新或直接移植生产。若继续该线路，主贡献必须具体落在强固定方法不能兼顾的总资源/时间边界、必要进度条件或更低成本的可证机制。需要新的独立差异证据，再谈四DMA/综合与FPGA，不能把本六次运行当旧PN根因或二区验收。
