# Codex 下一最小判别：小缓冲 copy 的让路边界

日期2026-10-08。根 Codex 独立选择与推演。以下均为设计／命题候选，未实现或运行。

## 先固定研究功能

主线仍是多 DMA 共享 IOMMU 下的性能与可控进度。选择一个具体需求：A 做长 copy，V 做短 copy；希望在 A 已启动后按有限工作量让路，而 A 仍可继续完成。当前 ResearchPort 的 ADMIT 在 backend idle 后才允许下一 job，不提供此项 copy 内部功能（`idma_reg64_frontend.sv:588–596`；`ariane_peripherals_xilinx.sv:1277,1287–1289`）。

这是一项拟评估的功能，不是当前已有 bug。AXI-REALM 已有预算＋分片，单纯增加细粒度门控不立新。问题缩到：真实读写边界错位、相同总缓冲与请求窗口下，达到给定让路范围至少需要多少分片／预先准备？如果普通方法有相同界和成本，就停止机制提案。

## 第一判别保持映射固定

不为制造反例增加 TLB 全局锁、旧 epoch 许可或未实现的 LTI 完成锁。新诊断规格只需要 `pause_new_source`：首次 VALID 之前冻结新增源工作；已 VALID 的请求不可撤回，必要目的翻译正常服务。旧映射持续合法。失效仅能作为以后单列的使用场景，不能把暂停 gate 当作 IOTINVAL 的真实语义。

先分析单 copy 的真实 byte 区间，再评估两 DMA。每条控制应得到相同 descriptor 信息、原父 window、全部 header／响应保存容量、数据缓冲和 W 顺序；不省完整 context／permission／error 字段。保持 A copy 成功是本项性能目标；合法 fault/discard 是另一项进度控制，必须报告 copy 失败，不能将其当同完成工作量的性能点，也不能将成功目标冒充标准失效安全的必要条件。

## 根推演：具体必要条件与普通解法

若要让其它 DMA 使用共享源返回路由与 W 队头，需要先释放当前物理 source child（到 RLAST）和当前 W burst（到 WLAST）。目的已写前缀为 q，覆盖 q 的最后一个必须完整接收的源 burst 末端为 r(q)。其多接收的 `r(q)-q` 字节必须在不会继续占住公共路径的真实 tail 存储中停放。

因此在“单 copy、只在目的完整 burst 处停止、没有其它源请求越过停止点、完整释放这两种共享资源”的受限模型中：

`safe_stop(q) => r(q)-q <= B`

B 是可以独立停放 tail 的全部真实 payload 容量。不能把名义48B iDMA FIFO当全部系统容量，也不能把仍占住共享 route 的 spill 中数据当可独立停车空间。若缓冲可以不完成 RLAST 就允许其它源服务，或 W 可以走另一独立路径，这个模型要相应修改。该式只给必要条件；进度仍需真实公平服务、响应路由与 AXI 合法性证明。

源边界0/2048/4096…、目的边界0/1024/3072/5120…且 B<1024 时，每个中间目的停止点都留下1024字节源 tail。如果两种公共资源必须同时释放而不能停放 tail，就会不断要求下一段读／写。有限单 burst 本身不界定整个 copy 的排空范围。

但是普通在目的边界额外切 source child 即可消除此例；§39的1KiB物理源 child 已经做到。iDMA legalizer 本身也有普通共同边界路径（`idma_legalizer.sv:199–214`）。所以此反例不能证明新后置位置或闭包准入独立。

## 只有成本界仍有差异才继续

令 H 为允许的最大两个可释放停止点之间的 byte 距离，它是工作量界，不是时钟时间界。有限 DDR/PTW 服务时间与无饥饿保证未证明时，不报告最坏时间界。

可以先把目的 burst 结束点作为节点；节点只有在尾部可停车或额外切源后才安全。相邻安全点距离至多 H；额外 source cut 收取1次物理请求及真实恢复 metadata 成本。按这个受限模型求最少额外 cuts，同时比较普通共同分段、固定 child、descriptor-derived 非均匀分段以及成对准备＋完整 tail 预约。

这个最优化的输入都能由普通 descriptor 和 legalizer得到，普通静态 splitter 可以实现相同解。最短路／动态规划本身不建立独立机制。要留下分析贡献，必须得到前作没有给出的锐界、说明为何已有保证不适用，并在真实平台中验证界及其有用成本点。没有这些增量就停止；不把一般 buffer 守恒改名为创新。

额外 source fragments 也不等于额外 PTW：普通父结果复用可消除重复命中请求，§39已示范同 miss/PTW 下不同数据服务时间。成本分别报物理 AR/AW、真正 TL 请求、PTW、全部 metadata、payload与两流完成量，不用 fragment 数替代翻译成本。

## 唯一下一步规格与退出条件

1. 先用源／目的实际边界和真实可停车存储清点判断上述单 copy 模型是否适用。已有 DUT 和原始日志仅定向引用，不重跑§39。
2. 比较理想最小前沿与同信息普通按片暂停。如果决定、保证和全部成本一致，立即淘汰闭包新规则。
3. 只有成本界存在明确差异时，再做一个 out 诊断副本：两真 DMA，保留普通物理旁路，暂停点由实际 AR 接收＋未完成目的准备共同触发；没有 pause 的功能基线必须一致。先试一个错位输入和一个共同分段强控制，不扩大扫描或 BIT。
4. 真正必要的检查是守恒与合法暂停：已 VALID 不撤回、正确 R ID/RLAST 与 W归属、未添加集合外请求、完整 bytes或明确错误结果、最终 quiet。新增状态与观测分开计费。

若只有人为 TLB 锁产生差异、普通按片暂停／静态非均匀分段同效同成本、公共 spill 已打断反例、应用只允许整 job 后 unmap、或工程通路错误主导，则不能立新机制。ShareMMU 适用性记录可以保留，但不能作为当前平台创新证明。

本文件确定的是后续判别问题和停止条件，不宣称新的保证已证明、算法已实现、实验已运行或达到某个论文分区。
