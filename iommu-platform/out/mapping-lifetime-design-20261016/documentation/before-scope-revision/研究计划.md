## V1：保留源回收的跨设备映射关联

固定官方v6.12普通page-backed mlx5e native XDP单页链，首版order0；复用上轮FIB/UDP/TX证据，不拼成原生运行。普通page_ref、pp_ref与pool对象引用不同，B空闲cache跨consumer持普通ref可能使页离开A pool。V1不让空闲cache加page/pp pin，将可撤映射绑定真实source owner；source退出须在release_cnt、清pp_info与put之前关关联/撤图。[资源核查](iommu-platform/out/mapping-lifetime-design-20261016/resource/findings.md)。

每次TX单独持binding token，完成先还token再还frame，持久map仍需每次sync。三逻辑FRAME FIFO槽中的dma_addr可替换handle只是表示草图，同样给普通O3；未编译、未证明零额外metadata。source/target并发关闭要唯一unmapper和配置寿命保证；同步不适合时明确Q保留页、metadata、worker与inflight责任，不能先丢owner再撤图。[owner/binding合同](iommu-platform/out/mapping-lifetime-design-20261016/root/owner-binding-contract.md)。

一般通知/反向关联已有dynamic dma-buf和DMA_PMD，策略增量对同接口O3为0。公平dma-buf adapter允许预export/attach、pool/span分组、自有range cache、控制面prepare、hot hit和miss defer/copy；不能强迫逐包export或每页一对象。dma-buf map的might_sleep/reservation与当前NAPI/原DMA API GFP_ATOMIC差异是可研究部署关口，不证明V1已经更优；owner通知也不自动完成DMA drain/硬件撤图。[近邻实质比较](iommu-platform/out/mapping-lifetime-design-20261016/prior/findings.md)。

相同有效工作与服务下，降低CPU费用或不可回收内存可作主要贡献，无需再次确认抽象授权/资源价值。实际部署事实未知只按条件处理。源池本来持有、B真正延后释放、copy目标新增和撤销隔离Q须按物理并集去重，映射不等于多一份payload，原帧早归还不等于总RAM下降。 固定外部到包、路由、consumer和服务合同，各策略分别导出真实recycle/allocation与再用，不强套同一PFN轨迹。metadata/PTE、IOVA、带宽和完成结果另列；普通pin造成的替代分配可能出现在另一页，copy目标池和Q都不能漏账。[资源卡](iommu-platform/out/mapping-lifetime-design-20261016/resource/resource-card.json)。

## I：失效粒度、live DMA与回收的共同费用

仅预筛一条正常map/unmap路径，核实共享关系、live DMA预算，以及命令、walk、完成和回收轨迹能否取得。[预筛报告](iommu-platform/out/research-plan-implementation-20261015/i/prescreen.md)、[源码证据](iommu-platform/out/research-plan-implementation-20261015/i/source-evidence.md)、[评估](iommu-platform/out/research-plan-implementation-20261015/i/assessment.json)分别记录来源、事实和未满足条件。

先排除当前驱动扩大失效造成的假缺口，并比较正确精确失效、合法批处理、持久映射和分domain。正常源码路径存在，不等于当前机器具有共置设备、超时预算或已测失效损失。若偶发完整walk已能由预算容纳，也不能仅凭可能的翻译抖动推导新机制需求。

本轮后端门补充：驱动有条件strict DMA-IOMMU通路；虽接受DMA_FQ类型，未声明DEFERRED_FLUSH导致通用setup回退strict，不能当成当前有效FQ合批。保存的构建config禁用IXGBE，当前DTS无对应PCI/ixgbe链，lowrisc Ethernet也无IOMMU关联，因此外部ixgbe源码不是当前固定profile的原生任务。保存配置不证明当前启动身份；仍无native运行/正确性测试。[I后端门](iommu-platform/out/d-source-gate-20261015/i-backend/findings.md)。

D未通过时，只有I已有明确剩余缺口与可取得证据，才提高I优先级；否则重审问题来源，不自动退回A。
