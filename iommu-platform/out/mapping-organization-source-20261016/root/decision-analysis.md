## 首先固定三种不同合同

用户尚未选择合同和主要收益；下列是分别分析，不替用户或导师决定价值。

1. **固定逐对象撤权。** 每个对象在既定结束点之后，B 不得再通过任何 alias 访问对应物理范围。大映射跨过第一个对象的结束点就可能非法；需要拆细、整页撤销，或其他已证明的隔离能力。把所有对象的 return/unmap 延到最后一个 CQE，会改变可见时机，只有任务本来允许这种延后且计入延迟才合法。
2. **有界整批授权。** 任务允许已选定的一批对象及其整页存储在统一 lease 边界前供 B 访问。可探索整页转交，但必须阻止该页提前回 A 分配器接收未知新包。A 允许常驻不意味着 B 可以读 CPU 分支；“可信集合”仍要列明对象与权限范围。
3. **原始对象隔离，允许设备专用影子存储常驻。** DMA shadowing 属于这种需要单独说明的语义：复制保护原始对象，不承诺每次 unmap 后设备无法读到影子页历史数据。不能把它与第1种物理撤权合同直接画等号。

Linux strict 模式只规定实际 unmap 的同步方式，不自动要求 page_pool 每包执行 unmap。因此，本轮不宣布现有 page_pool 违反 strict。实际粒度还取决于 IOMMU 最小页、padding、alias、bounce 和 coherency；不能从 buffer 长度推出逐字节隔离。

## 可发展的正向版本：有界整页转交

在合同2允许的范围内，可以尝试以下协议。它是**拟议设计**，不是当前 page_pool 已具有的能力。

1. A 按真实可知信息接收；RX 后用正常 classifier 得到各对象的实际目标。只在固定小时间窗和固定内存预算内收集候选批，不能等待未知未来填满 PMD。
2. 选择一个 PMD，关闭它的新 RX 分配与补描述符。取回 cache 中的空闲块，等已发布的 A DMA 完成；保持所有块和归还回调归属可追踪。其他 PMD 继续供给，但替代页、额外占用和等待都收费。
3. **在 skb／外部引用发布之前**，将 CPU 或其他目的的少数对象搬到合法存储。不能事后移动任意 live skb。清除原页遗留、空洞和敏感元数据；清零不是授权，要确认整页字节可以授予 B。
4. 按合同撤销 A 及其他旧授权、完成所需同步，再向 B 发布整页映射与帧。若合同允许 A/B 同时访问，保留也须明确列出，不默认为免费。
5. 子帧完成只记账，不把任何块交回 A 接收未知新数据。全部 DMA、fragment、引用和批量归还义务结束后，撤 B 映射并确认同步，才解封回 A／一般分配器。失败与 B 只接受前缀时，也只能由唯一 owner 清理。

不足一批、路线分散、长尾引用或不满足 revoke 截止点时，及时退回普通小映射或合法复制；不能丢包、无限积压或无限备用池。当前源码没有 PMD cohort 所有权与上述转换，须先逐项标明可复用钩子和必须新增且付费的接口，不能用一个“seal()已成功”的假接口跳过困难。

两个实现关口需要特别早查：现有 `mlx5e_xdp_handle` 在 action 返回后立即调用 `xdp_do_redirect`，因此“路由已知、尚未向外发布”的新决策点必须显式插入，并保存目的引用／有效性与每帧状态；不能免费重跑可能有副作用的 BPF 程序，也不能长期借用 per-CPU redirect 临时状态。另一个是已贴到 RX WQE 的页：若硬件只能整队停机而不能按 PMD 撤下，这就是必须计费的实际限制，不能假设局部 seal 不影响其他供给。

这里的研究空间是：**能否实现并复用这条转换协议，并找到在同合同、同服务和同预算下值得执行的范围。** 选择 dominant destination、搬少数和画权限图都不足以独立构成论文贡献。若普通同信息协议完全等价，停止该策略增量主张；若仍有更少同步、更小状态、可验证集成或完整成本差异，要拿具体实现和证据论证。

## 现在可推导的费用条件

令一个已观测批的有效 payload 为 \(L\)，其中去 B 的比例为 \(f\)，PMD 物理大小为 \(H\)。候选至少支付

\[
C_{loan}=C_{seal/drain}+C_{evacuate}((1-f)L)+C_{scrub}(H,layout)+C_{map/revoke}+C_{metadata/cache}+C_{hold/refill}.
\]

对照为同合同下的实际小映射费用 \(C_{small}\)、复制去 B 的 \(C_{copy}(fL)\) 加合法 B 池费用，以及允许时的持久映射／普通同信息批处理费用。所有项保留参数，不用未测数字填成胜例。

只有当候选满足吞吐、延迟、内存与撤权限制，并在用户认可的资源目标上优于具名最强可执行对照，才值得进入收益验证。**去 B 比例大于一半不保证划算**：搬走少数后还要擦掉原处，未填满 PMD 的空洞与头尾空间也可能需要处理；等待整批会延迟 CPU PASS 和早完成对象的释放。

正向预测：已观测批具有稳定多数目的、合同允许有界 batch lease，且全费用低于逐页转换／全复制时，有合法非空优势区间。相邻反例：固定目的可预分池、全池本来可共享、普通分池/复制规则等价、最早 revoke 截止过紧、批太稀或长尾占满预算。只证明条件区间不等于证明正常流量出现该区间。

## 候选二的准确位置

两个最终依赖已经在同一驱动快照找到：PASS 的 skb 最后 dataref 与 REDIRECT 的 B TX CQE／return。**它们同处一个物理 PMD 尚未建立**；不能把新 RFC 与旧 Linux 接成已经运行的原生实现。

即使构造来源投影，也须加入 pool cache 对底层块的持有；按最终消费者分组而不控制 cache，未必形成 idle PMD。关闭选定页的新分配可能有用，但普通 per-queue pool、按释放批次 arena、MRU、合法拆页／迁移同样是强对照。无消费者完成与回收服务上界，就无有限回收期限保证。因此暂不另建模型；候选一若明确长期共享合同，或来源显示同 PMD 不同依赖有实质保留费用，再提高此分叉优先级。

## 下一项具体工作与论文增量判据

必须同时处理：提前 CQE、cache回流、RX在途、B接受前缀／失败、最后引用、不同逐对象 revoke 截止。若一条不变量无法实现，给出精确反例并重设计该协议；若协议可行，再冻结同信息普通实现和完整费用输入，决定是否值得做一个模型。
