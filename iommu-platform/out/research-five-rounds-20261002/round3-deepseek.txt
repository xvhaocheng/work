## 3. 方案 M：完整方法假设合同

### 3.1 RQ / Hypothesis / 预注册判定式

**RQ**：在 A 每字节翻译成本随局部性变化、且共享翻译控制是单 FSM/非抢占的前提下，按"A 归属的共享翻译控制占用周期"计费来准入 A 的下一份完整 4 KiB copy，是否能在**相同 V 进度容差**下比按字节计费、按 miss/PTW 计费、以及纯 V 进度反馈保留更多 A 有效工作？

**H-M1（点假设，可证伪）**：在预注册的非平稳 A 局部性负载族上，M 相对 {字节计费、miss 计费、V 进度反馈} 中**最优者**，在 V 目标达成率带内（§4 冻结 ν=3pp）使 A 有效工作提高 ≥ μ=2%，且该差异在独立测试集上的 cluster-bootstrap 95% CI 严格 \(>0\)；同时相对**同成本时移 placebo** 亦成立。

**H-M0（前置可证伪）**：在 A 字节/拷贝数/起始相位相同的三臂局部性下，`S_A/byte` 存在超出噪声的差异。

**判定式形式（Round 4 需冻结的具体形式）**：
- 设 `T_v(p)` = 测试集中满足 `v_w ≥ v*` 的窗口比例；`A_tot(p)` = 测试集 A 有效完成字节。
- 主判据：在 `|T_v(M) − T_v(base)| ≤ ν` 的匹配带内，要求 `A_tot(M) / A_tot(base) ≥ 1 + μ`。
- 副判据（完整 trade-off 曲线，不设阈值，全部报告）。
- 消融判据：`M` 与 placebo(IB-D)、与等 duty 固定周期(IB-F) 的差分别给 CI。
- CI 跨零 → **证据不足**；不写等价、不写 p 值裁决（`round2-deepseek.txt:138` 与 `round3-codex-input.txt:14` 并存：CI 为主，p 值为辅且非决定性）。
- 不使用 `v_solo` 的排队长度作分母；`v_solo` 由新同版 solo 运行中位数给出（§4）。

### 3.2 信号定义、单位、计费集合、归属、未计费压力

**时钟单位**：全部计数以 `clk_i` 周期为单位（当前实验 50 MHz 假设，`shared-facts.txt:5`；这是实验假设，不是规格承诺）。窗口 `E` 亦以周期计。信用/欠账单位 = **周期**（与现有 gap 1000/2000 周期同量纲，`shared-facts.txt:9`）。

**计费集合 B_A（每周期最多计 1，优先级 `wait_ptw > downstream > sel`，避免重叠双算）【待建】**：

| 计数名 | 增量条件（周期） | 计费？ |
|---|---|---|
| `S_A_ctrl_wait_ptw` | 控制器因 A 归属请求而等待 S1/S2 页表响应 | **是** |
| `S_A_ctrl_downstream` | A 归属译后请求 VALID 且下游未 READY（控制边界背压） | **是** |
| `S_A_ctrl_sel` | 控制器正在服务 A 归属请求的其余占用周期 | **是** |
| `U_A_post` | 下游已接受之后到 `trans_complete`（写排空/AW-W/数据出口等待） | **否，单独上报** |
| `U_A_fifo` | A 归属对共享 AW/AR（各 1 个）FIFO 的占用 | **否，单独上报**（共享单 FIFO，设备归属歧义） |
| `U_other`（全控制器视角） | 非 A 请求造成的控制器占用/背压 | 否，作为混杂上下文 |

**必须明说的两条**：
1. **排除数据地址出口等待**的理由：AW 优先用于写排空（`shared-facts.txt:5`），该等待属数据通路；且"已 VALID 未 READY 的输出不可撤换"（`:11`）⇒ 把它计入会奖励不可控项。排除动作**必须伴随 `U_A_post`/`U_A_fifo` 的逐窗上报**，否则等于隐藏压力。
2. **hit 无需未来预知**：计费是事件/周期驱动的，**不查询** hit/miss、不查询 IOTLB 条目状态、不做任何前瞻。因此运行时**不依赖 E2**；E2 只影响结果解释（§5-L3）。

**归属（owner）**：
- 首选：请求侧标签 `burst_req.opt.device_id` / `process_id`（`idma_reg64_frontend.sv:311`、`:314–316`，由模块参数 `DEVICE_ID/PROCESS_ID` 固定，`:20–22`）。
- 前置核对：该字段是否在控制器/PTW 全生命周期保留；若不保留，需新增 A 端口旁带标签（**待建**，成本计入 §3.7）。
- **禁止**：用 DID 去决定翻译命名空间/缓存标签（`shared-facts.txt:11`、`round2-literature.txt:28`）；用 FIFO 占用做归属（共享单 FIFO）。

### 3.3 有限离散控制规则（只用当前/过去输入）

**状态（整数、饱和）**：
`q`（信用，周期，∈[0,Qmax]）、`debt`（欠账，周期，∈[0,Dmax]）、`b`（每窗补给，周期/窗，∈[Bmin,Bmax]）、`win_used`、`v_prev`（上一窗 V 有效完成字节）、`no_v_windows`、`win_since_a_release`、`debt_sat_q`（粘滞）、`starv_flag`、`hold_cycles`。

**规则**（`win_tick` 每 E 个 `clk_i` 周期一次；所有更新只读过去）：

- **R1 计费（每周期）**：若该周期属于 B_A：`q>0 → q←q−1`；否则 `debt < Dmax → debt←debt+1`；若 `debt == Dmax` 且再来计费周期 → `debt_sat_q←1`（**不再累加**，见 R4 安全）。
- **R2 窗口补给与还债（`win_tick`，顺序固定：先还债后补信用，再评估 `b`）**：
  `x ← b`；`r ← min(x, debt)`；`debt ← debt − r`；`x ← x − r`；`q ← min(Qmax, q + x)`；`win_used` 清零；`win_used/k` 归档供日志。
- **R3 `b` 反馈更新（`win_tick`，只用上一窗 `v_prev`）**：
  `e ← (v_prev − v*) / v*`；
  若 `|e| < δ` → `b` 不变（死区）；
  否则 `Δ ← clamp(round(g · e · Bmax), −Δmax, +Δmax)`；`b ← clamp(b + Δ, Bmin, Bmax)`。
  （符号：V 低于目标 ⇒ `e<0` ⇒ 减少 B ⇒ A 少占；V 高于目标 ⇒ 放宽 A。**只用上一窗**，不用未来。）
- **R4 放行决策（只在合法边界评估）**：仅当 `trans_complete_i` 后控制器处于"上一 copy 已完成、下一 copy 未提出"的边界（现成落点：WAIT→GAP / GAP 到期，`:508–529`、`:533–546`）且无在途 A 请求时，才评估：
  `release = (q > 0) ∧ (debt < Dmax) ∧ ¬debt_sat_q ∧ (state==IDLE 或 GAP)`。
  等价语义：**不得在 `q==0 && debt≥Dmax` 或 `debt_sat_q` 置位时放行**；已有 `VALID` 的请求一律不撤回（`:489–491` 注释：VALID 保持、地址稳定）。
- **R5 欠账恢复**：`debt_sat_q` 只有在 `debt ≤ Dhys`（迟滞）时清零；期间 **只允许** R6 的饥饿保底放行。
- **R6 A 最低进度（有界，不是硬保证）**：`win_since_a_release` 每窗在无放行时 +1；`≥ W_max` → 强制放行一次并置 `starv_flag`；否则在下一窗 R4 评估时优先。
- **R7 V 起止**：V 开始不做特殊动作（但要分窗标注边界窗，稳态指标剔除边界窗）；`no_v_windows`：若 `v_prev` 连续 `E_null` 窗无有效进展，则 `b` 冻结在 `b_frozen = B0`（**不**上抬到 Bmax，避免 V 回来后恢复过慢），并置 `v_absent_flag`。
- **R8 STOP / 复位 / 超时**：STOP（`0x88 wdata==2`，`:166`、`:537–539`）**优先于任何放行与倒计时到期**，排空当前 copy 后回 IDLE，政策解除武装；复位（`batch_enable wdata==0`，`:173–178`）清 `q/debt/counters` 并令 `b=B0`；`hold_cycles > T_hold_max` → 放弃准入控制，退回固定 gap（`POLICY_FALLBACK`）并置状态位。

**边界冲突先后（冻结）**：
1. 复位 > 2. STOP > 3. `win_tick`（先 R2 再 R3）> 4. 计费（当周期计入当窗，不跨窗重复）> 5. 放行评估（用 R2/R3 之后的新值）> 6. 普通寄存器写。
**明说的不保证**：下游无界时**不保证硬实时**、**不保证 A 永远前进**、**不保证 V 到达时能收回在途资源**（可借的是"未来可恢复的准入机会"）。

### 3.5 为什么可能优于纯 V 进度反馈 + 让 M 输的负载（必答）

**可能优于的理由（假设级，不宣称已证）**：V 进度是**滞后**量——只有在 V 的完成率已经下降后才改 `b`；而占用计费在 V 完成率尚未下降、但共享控制已被 A 饱和、V 请求已在共享 FIFO/控制器排队时就扣额度。且当 A 的**每字节控制成本**随局部性变化时，字节计费在"同字节、高成本"的局部性上系统性超发；miss 计费在"同 miss 数、重复占用"时系统性低估（纯 hit 不必占 miss 槽，`shared-facts.txt:11`）。

**能让 M 输的负载（提前写出）**：
- **L-loss（数据主导）**：A 的控制占用在三种局部性下几乎不变，而 V 损失由下游数据通路/突发形态主导 ⇒ M 的计费量与字节计费几乎同形，纯 V 进度 PI 打平甚至更好 ⇒ `H-M0`/`H-M1` 同时失败，按 §5-S2/S3 停止。
- **L-quant（量化锁步）**：A 的局部性阶段长 < 2E 或 V 到达周期 ≈ E ⇒ 任何窗口策略的优劣由相位巧合决定 ⇒ 必须靠随机相位与 IB-F 等 duty 固定周期对照来暴露。
- **L-cold（冷启动）**：A 首次触页的 miss 主导期，miss 计费反而更贴合 ⇒ M 无优势。
- **L-solo（V 缺席）**：M 在 V 缺席时退化为接近无节流 ⇒ 与 gap0 无差，属预期，不算失败但也不能计为收益。

## 4. 等信息强基线（IB）与公平性冻结

"等信息强"= **同一传感器集合、同一更新率 E、同一作动点、同一 `Qmax/Dmax/Bmin/Bmax`、同一公式形状与同一评估预算**，只改**被计费的对象或信号**。每臂在训练集上最多评估 32 组配置，预算相同；测试集只跑**冻结后**的单点配置。

| ID | 定义 | 作用 |
|---|---|---|
| IB-A | 同规则，计费对象 = A 已发字节（配额以字节计） | 检验"占用 vs 字节" |
| IB-B | 同规则，计费对象 = A 归属 miss/PTW 事件数 | 检验"占用 vs miss" |
| IB-C | 纯 V 进度 PI（同 E、同作动点、无任何 A 信号） | 检验"新信号是否有增量" |
| IB-D | **同成本 placebo**：占用信号时移 1 窗或按训练期固定置换 | 检验"收益是否只是周期性干预" |
| IB-E | 固定 gap 族 {0, 1000, 2000} + **本 V/A 对上新调**的一个静态 gap（训练集选，冻结） | 日常最强静态对照 |
| IB-F | **等 duty 固定周期模式**（平均 duty 等于训练集上 M 的平均 duty） | 检验"自适应只是打散同步" |
| IB-G | 离线 oracle（同一冻结网格内事后最优） | **上界，标注不可实现**，不作在线政策 |
| — | 现有 60 例 P4M | **仅参考**，跨 boot（`shared-facts.txt:9`），不当作同版对照 |

统一口径：所有臂报 V 分窗 + 整批、A 同窗 + **V 结束后的 A 尾部**、目标未达、过冲/欠账、A 吞吐、最大观测等待（非最坏界）、短时振荡。

## 5. 最小实验层次与停止条件

**L0｜接口/可观测性门槛（不上板；RTL 功能级/主机工具）**
- 检查 (a) A 不发请求时 `S_A=0`；(b) 冻结单局部性 A 循环下 Σ`S_A` 落在 [0, 拷贝数×C_max]；(c) GAP 期间 `S_A` 不增；(d) **hit 若占控制路径则被计费**且 `S_A ≤ A 控制路径总时间`；(e) 饱和+sticky overflow 不回绕；(f) 归属标签在控制器/PTW 全生命周期保留（K-M6）。
- 成本门槛：报新增 LUT/FF 与 Fmax 影响，超阈值（建议 ≤2%，由 Codex 定）先改设计。
- **S1**：任一 (a)–(f) 不成立 → **不上板，不主张政策**；M 保留为未达观测门槛的方案。

**L1｜同包小规模自然 4 KiB 诊断（单次烧录，多模式）**
- 三臂 A 局部性：A8 现状（8 src/dst 页集）/ 单页高复用 / 跨页低复用；**字节、拷贝数、起始相位、gap 均相同**；V 固定。
- 观测 `S_A/byte`、`U_A_*`、V/A 分窗。
- **S2（前置可证伪）**：三臂 `S_A/byte` 在 CI 内无差异 → 杀死 D-α，M 失去存在理由，转边界/负结果，不进入 L2。
- 允许用受控 64 B 与 128 周期注入**仅校验探针口径**，不得作自然量级（`shared-facts.txt:7`）。

**L2｜冻结训练 + 独立测试（同版本对照）**
- 训练集：预注册的 A 局部性阶段切换（阶段长 <2E / >4E）、V 突发周期 ≈E、以及数据主导负对照；冻结种子与相位；只跑 IB-A/B/C/D/E/F 各 32 组配置上限。
- 测试集：不同 boot/种子/相位排序，训练期从未见过的参数点；**随机交错政策模式与固定模式**的预生成种子调度（控制器只见过去信号）；报告交错调度的日志与"交错本身改变到达过程"的限制（`round3-codex-input.txt:13`）。
- **S3**：主判据不达标（M 未超过 {IB-A, IB-B, IB-C} 最优者，或 CI 跨零）→ **停止 H-M1 主张**，不再调参挽救。
- **S4**：IB-D（同成本 placebo）打平 → "信号的信息价值"死，只留"周期性干预"。
- **S5**：成本/Fmax 门槛失败 → 改设计或放弃。
- **S6**：出现 `hold_cycles>T_hold_max`、`starv_flag` 频繁、或下游无界 → 必须 `POLICY_FALLBACK`；**不得**写硬实时或 A 永远前进。
- 矩阵上限：不无限扩；最多 2 个 E × 2 个 B0 × 3 个 g 的粗筛，然后单点冻结。

**L3｜并行、有界的 E2 混杂检查**（非前置）
- 目的仅是把"A 局部性→IOTLB 容量/替换状态"这一混杂**有界化**：报告三臂的命中/替换可观测量与 `S_A` 的分离程度。
- 若混杂无法被任何现有对照界定 → M 的结论收窄为"对可观测信号的控制政策"，**不**归因到共享翻译服务占用。
- **禁止**把 E2 设成必须成功的前置（`round3-codex-input.txt:13–15`）。
