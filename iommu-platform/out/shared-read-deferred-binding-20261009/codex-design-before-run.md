# §72 Positive mechanism: common repair before an abortable rendezvous

Codex design before execution. §71 start-time heuristics use only the earlier V service, so they cannot observe later A behavior; consumer-hold estimates also mix joint completion and V latency goals. Dynamic merging windows themselves are prior art (Intel US20200402198A1), so a timeout is not the novelty claim.

Mechanism: A first issues an independently authorized fixed prefix [FA,E), while the already accepted V physical prefix/tail continues unchanged. This common operation commits to neither future mode. Only after old V true RLAST and logical cursor E can the controller bind the future route. A shared suffix is permitted only after both logical cursors and actual raw W cursors reach E, with the skid empty. Existing B debts may remain. Otherwise a finite budget of eligible rendezvous cycles expires and binds independent future reads. A prefix already offered/accepted is never resized or withdrawn; A later independently reads [E,N) and V reads its own [E,N). No payload storage is added.

Policy wait is bounded, not end-to-end latency: future interconnect service, a held A AR/R/skid, target W and old B can still stall a flow. A timeout cannot retroactively fix a previously offered message. Counter ticks only after true V physical/logical prefix retirement and before binding; expiration has no dependency on A readiness. Budget0 is the strong common-prefix independent control, long budget approaches safe sharing. Compare with §70 ordinary independent single-A-AR and safe fixed sharing too; common-prefix independent pays an extra AR. Do not bury that cost.

RepairWaitBudget=0/64/1024/4096 are compile-time experimental contracts, not oracle DDR intervals. All paths use Q2/B3/Max2B, equal successful independent grants, immutable normal same PA, single2KiB jobs. R work: shared E+256, independent512; actual selected path determines expectation from RTL state, not measured R count. Prefix-to-joint correctness gate closes payload debt without waiting for all B acknowledgments. NEW W clipping applies to both prefixes in phase3 as a second safety gate; existing firstVALID children remain unchanged.

Acceptance: both paths and real budget expiry, complete byte guards/256 target W each, actual source cardinality, exact bounded counter rule and baseline route differences. Critical source audit must check later binding versus old V LAST, A prefix/suffix main metadata, possible simultaneous V/A AR creation, registered headers, phase2/3 write clipping and B debt. General faults, remapping, multi-job/repeated pause and equal synthesized area are outside this prototype.

Contribution test: if asynchronous authorization plus irrevocable requests creates a failure/cost not handled by prior merging-window/MSHR/multicast designs, and this common-prefix/debt-complete join removes it at measured bounded cost, it can support an independent mechanism contribution. A timer, generic repair, broadcast, and current bandwidth savings alone cannot. No claim that the complete combination has never been published without checking the nearest primary work.
