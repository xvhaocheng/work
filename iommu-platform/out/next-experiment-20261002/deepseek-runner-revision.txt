## Findings summary (what was wrong, what this revision changes)

Verified against the supplied log (`runner-first-test.log`, 14/27 failures):

1. **Count semantics bug (all 84-case runner failures).** `plan_check` counted `n_e2`/`n_cost` across *all* stages (63/21) and compared them to 60/18, so every run that validated the frozen TSV died at `PLAN: e2_count want=60 got=63` before case 1 (`out-all`, `out-short`, `out-argv`, `out-dmesg`, `out-sibling`, and `test_*` all show exit 2 instead of 7/3/5/0). Fix: counts per stage — short e2/cost 3/3, **main** e2/cost 60/18, all-stage totals 63/21; `counts.e2`/`counts.cost` stay MAIN counts, all-stage totals get explicit keys.
2. **Cost `acount` was wrong by design.** `acount = vcount` encoded "A count == V count". Cost mode's A (P4M) batch *continues until V finishes* and is then stopped/drained, so `acount` is not applicable → 0 (solo also 0). Fixed in generator, TSV, AWK check (`cost_acount_not_applicable`), tests, plus a manifest `mode_notes` explanation. CLI args unchanged (`--cost --a-pages --a-gap-cycles --transfers --warmup --timeout-ms`).
3. **`json_object_check` removed entirely.** It was an awk brace-counter that accepts `{}`, `{garbage}`, `{"a"[}`. Runner contract is now bounded: CLI exit 0 + non-empty stdout artifact + taint 0 before/after. Semantic JSON validation is the CLI's own contract via its exit status, which is propagated. Host test now does the `json.loads` on the artifact.
4. **Console flood removed.** No more `cat <case>.json` (4096-byte copies → huge UART dumps). Success → one compact `case_end` line; failure → bounded `tail -c 2048` of stderr; full files always kept in OUTPUT_DIR for the existing board return-file archival.
5. **Plan-freeze copy safety.** The plan is copied once to `OUTPUT_DIR/plan.copy.tsv`; header check, data rows and per-case argv all read the copy; `plan.sha256` hashes the copy (never the mutable original); hash-tool availability is recorded honestly (`hash_tool=none`, `plan_sha256=unavailable`) instead of silently omitting the file.

Unchanged on purpose: 84 frozen case sequence, fail-stop, dmesg raw collection, taint gates, no retry/resume, CLI flag spelling.
