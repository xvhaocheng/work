# 有界纸面判别与相邻反例

这里只作手算状态/动作比较；0性能模型、0实验序列、0新采集、0旧trace/validator回放。以下身份和事件由合同构造，不冒充真实工作流/板端原始观测。没有周期、PTE服务延迟或性能数字。

## 固定的最小任务结构

四登记任务、最多两原生源：

| task | copy | 依赖 | 数据完成义务 |
| --- | --- | --- | --- |
| P | context0下X→Y，64B | 无 | 真实目的B后可使C就绪；Y仍归consumer |
| C | 同context0下Y→Z，64B | P真实成功完成及cache交接 | 完整copy和真实consumer后解除Y的最终owner |
| B | context1下A→B，64B | 无 | 固定后台有效工作，正常R/W/B/最后校验；目的保持到终末释放 |
| D | context1下T→U，64B | 无 | 同样固定后台有效工作和终末释放 |

两context独立授权；名字只表达地址，非免费跨domain共享。源0顺序执行P/C，源1顺序执行B/D；每任务只在实际backend idle、合法64B/HOLD或软件pre-kick边界发起。4×64B=256B是**合同名义工作量**，R/W实际字节、PTE数量、响应及完成向量未测均null。四任务不是四个新增性能条件；登记四槽不增加并发。没有扩大工作集、预热、相位或内存延迟来求收益。

### A：信息能改变决定，不能证明独有收益

共同ready集合是P/B；B登记年龄更老，源RR也先指向B。当前两者名义字节、已知miss/新页率相同。Y被已登记consumer拥有，P→C是解除Y义务的链；后台B不解除当前Y义务。

- 只看当前速率/年龄：可先B。
- CO1：先P；本次越过B后，下个合法机会先B。
- 同信息release/祖先优先普通控制：也可先P并采用同样公平约束。

这仅给低信息规则的选择差异，不给CO1对同信息普通的差异，也未证明先P能缩短全部四任务完成。

相邻输入：C已经真实完成并解除Y；保留当前P/B的可选择输入信息时release_path不再优先P。它是信息区分对，剩余任务状态有变化，不能把这两份输入的绝对完成时间当固定工作量性能对。

### B：翻译用途可以先退休，buffer不能

P的X最后AR和Y最后AW已真实交接；P的B还未返回、C尚未ready。登记还包括C对Y的未来read。

- X的最后登记翻译用途为0，可以解除保护。
- Y仍有C用途，保护继续。
- Y的数据owner与P完整完成义务继续保留；不得提前触发C消费。
- 普通逐用途引用计数/用户位图：同样得到X计数0、Y计数1，无需增加另一份prepared cache或等整个flow结束。

相邻输入：X还会被登记后继使用或还有另一burst未交接，则X不能解除。若缺精确最后用途反馈，双方保守等完整任务终结。

### C：保护耗尽与释放链

假设一般边界快照全部way受未来用途保护，而下一合法ready任务需要不能由保护集合满足的新fill。不能冻结它直到未ready consumer来释放保护：CO1会牺牲保护/回普通victim，允许未来重walk，完整RWB安全不变。

本轮K=16登记、缓存16的有限例子不自行构造第17个登记页来制造此状态；若新任务超出登记范围，必须整体普通回退。这是容量/循环等待**边界检查**，不是该固定256B任务已达到的性能正例。有限pin加普通逃生同样可以实现它。

### D：已发布VALID

COUNT已经发布后，新增DAG提示/保护变化不能撤回本任务。只能影响后续未发布任务；保护策略若要求撤回，则该动作非法。CO1与普通都保持原payload/full ID及原生R/W/B。

### E：失效、错误与取消

- stale epoch或相同IOVA不同domain不产生共享/许可；关闭提示并走正式路径。
- 未发布任务可撤销登记用途；已发布任务先保留data债务并完成正式错误终结/排空，不能用bit清除冒充B/consumer完成。
- mapping invalidation必须优先，不被pin阻挡；已经接受的PA另有真实owner，epoch增加不回收它。

### F：普通方法已经覆盖

没有consumer复用、全部活页都能驻留、合法大页/准备已经覆盖、页保护开销高于重新walk、或者整体最后仍等待同一后台任务时，保护/先完成局部任务不能自动形成完整gain。全部保留为候选边界，不据此改工作量或搜索参数。

## 本卡能支持的结论

信息与合法动作可作有界设计；具体普通覆盖须由冻结程序和同信息成本映射接受。所有手算都不提供实际任务完成、面积/Fmax、GPU/AI来源或FPGA收益。只有剩余动作或逻辑成本差异存活，才另立最多四新性能条件合同。
