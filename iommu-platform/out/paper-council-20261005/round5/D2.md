**状态**：本轮只读所给 R1–R4 六方、`R5-plan-boundaries.md`、`R4-review-boundaries.md` 与已转引源码/文献点验。未执行任何探针、模型、仿真、构建、板测或 SD 操作。下文全部为计划与判断，不是已验结果，不声称发现漏洞或性能收益。R5 之后不自动实现。

## 2. 首选研究问题（唯一，离开 P/N/PN 框架）

**D2-R5-P1（首选 RQ）。** 把问题从“共享翻译资源怎么分”重新定义为：

> **在固定规范版本与固定官方 ref 下，共享 IOMMU 的“完成/可见性”事件（submitted、processed、G、Fdone、AV 观察、安全复用）在现实主机桥/互连接口中是否可观测、可证、可组合；是否存在一条现实接口行为，使“官方 ref + 真实 PR/PW 回调 + 普通 per-request/epoch scoreboard（B-score）”在同等观测/状态/事件预算下无法判定——误报一条合法重排，或漏报一条非法越界——而一条更少状态或更少事件的分解规则可以判定；并且该差异在第二个独立接口/实现上产生可复现的同类后果。**

**为什么这是最有信息价值的开放问题**
- 它的两种答案都改变后续投入：
  - **B-score 覆盖** → 验证/接口方向整体关闭，省下后续一切 RTL/仿真投入；
  - **存在非平凡差异且有第二实现后果** → 打开一条**接口知识/验证**论文，并**重开机制方向**（见 §6）。
- 它**不是**重述 O1–O6：任务边界明确禁止把已能手工覆盖的 O1–O6 再测一遍当发现（`R5-plan-boundaries.md:7`）。本 RQ 的门槛是“同预算下的具体行为差异 + 现实接口后果 + 第二实现”，不是覆盖率百分比。
- 它**不是**只打弱单值 oracle：任务边界明确“仅能写成 scoreboard 不足以一概否决语义/接口知识贡献，但必须给非平凡差异、现实接口后果、成本/状态缩减或泛化证据”（`R5-plan-boundaries.md:4`；`round4/C2.md:71`）。本 RQ 的门槛正对应该条。

**强对手必须一次定死**：官方 ref + 真实 PR/PW 回调 + 逐请求/映射版本/epoch scoreboard，同请求上限、同 trace 长度、同运行时间、同内存预算；候选不得看内部信号而对手只看软件日志，不得给候选更强设备前提（`round3/C2.md:78-85`、`R4-review-boundaries.md:17`）。

## 3. 备选（唯一）

**D2-R5-P2（备选）。** 只对**已有 172/`metrics.csv`** 做**回溯诊断**：用固定参数的非抢占交替服务/闭环供给模型 S0（参数来源与允许变化范围事先写死，单 boot 三 block 只作工程重复），预测未参与拟合条件的 V 窗口与**共同窗口完成率** `a_completed_jobs_window / v_window_cycles`，报告残差。

- 明确定位：**回溯诊断，不是预注册确认**（`R5-plan-boundaries.md:5`）。

**为什么是备选而非并列首选**：它是方法/负结果候选，本身不产生接口后果，也不重开机制方向；只有在 P1 关闭、且仍需一条“本平台现象是否可由普通模型解释”的结论时才值得做。

## 5. 顺序、交付物、成本层级、证据门槛

### 5.1 顺序（严格先后）

1. **P1-a（先，必做）**：接口完成语义合同 + B-score 对拍。成本 **只读 + 现有数据/纸面 + 小模型**（L0/L1）。
2. **P1-b（仅当 P1-a 给出非平凡差异才做）**：第二独立接口/实现的同类后果核查。成本 **只读 + 纸面**（L0/L1）。
3. **P2（可与 P1-a 并行做，但晚于 P1-b；纯 L0）**：S0 回溯残差。
4. **仅当 P1-a ∧ P1-b 过门**，才谈 L2 最小仿真/软件对照；**仅 L2 过门**才谈 L3/L4。本轮不进入 L2 以上。

### 5.2 具体交付物

**P1-a 交付物**：一份《完成语义接口合同（只读版）》，含
- 固定规范 commit 与固定官方 ref commit（不得引用未固定 main，`round3/C2-literature.md:3`）；
- 抽象事件定义：submitted / processed / translation response / G / Fdone / AV 观察 / 安全复用，并写明**哪些现有信号不能推出它们**；
- B-score 伪代码（含状态与事件预算）；
- 三分类判定表（已证违反 / 在明确前提下满足 / 信息不足）；
- **一条（或一类）B-score 误判的具体行为对**，或“无差异”的明确结论。

**P1-b 交付物**：第二接口/实现的失配清单，或“未找到”的明确结论。**不得用 seeded mutation 冒充第二份独立真实证据**（`R5-plan-boundaries.md:4`；`round4/C2.md:79`）。

**P2 交付物**：回溯诊断报告，含 S0 参数来源、拟合/留出划分、残差表、whole-round 尾段单列。

### 5.3 证据门槛（go / kill）

**P1-a**
- **Go**：在固定规范/ref commit、同观测/同状态/同事件预算下，给出一条**具体、现实可达**的行为对，B-score 误判（假阳或假阴）而候选判定正确；候选**不缩小任何 IOFENCE 义务**、不使用未来信息、不预取（`R4-review-boundaries.md:16`）。
- **Kill**：B-score（或其直接接口扩展）覆盖同一错误集合且成本相当 → **整个首选方向关闭**，该方向只留一份工程断言/验证资产（`round4/C2.md:81`、`round4/D3.md:78`）。
- **信息不足即停**：若关键事件（如 G）无法从现实接口获得，且不能通过常规同步解决 → 记“不可判定”，**不得**据 TODO 发布漏洞结论（`R4-review-boundaries.md:9`）。

**P1-b**
- **Go**：第二个独立接口/实现出现**同类后果**，且不是本地 harness 的偶然缺口。
- **Kill**：只在本地 harness 复现 → 降为本地验证资产。

**P2**
- **Kill（降级）**：S0 在留出条件上正确预测方向 → 现象先归普通排队/仲裁/闭环供给。
- **不构成 Go**：残差大 ≠ 创新成立；只能触发“设计 per-request owner trace”这一后续判断，且需另行预注册。

## 6. 停止/转向条件与“重开机制方向”的真实新证据

**何时可以停**
- P1-a 判 Kill → **首选 RQ 结束**，写“无正式论文主线获准 + 保留验证资产”。
- P1-a 判 Go 但 P1-b 判 Kill → **只保留本地验证资产**，不立项接口论文。
- P2 判降级且无需方法线 → 备选也结束。
- 两者皆停即终结本方向，不换名。

**真正需要的新证据如何重开机制方向（只给一条重开路径，不再列候选）**
- 只有当 P1-a/P1-b 证明：**现实接口无法支持某个完成语义的必要观测**，且该缺口是**第二个独立实现也共有**的、不能被常规同步/epoch 跟踪消除的——那么任何依赖该完成语义的机制（含被撤回的选择性复用类设计）都必须**重新定义其“可验证保证”**，而不是继续在既有观察上宣称安全/收益。
- 这就是重开“机制 + 可验证性联合”方向的唯一入口。前提是**真实接口失配 + 第二实现后果**，不是本地 TODO、不是模型投票、不是新命名。
