# D3-R3 回应与重构：撤回换名机制，保留四类问题的低成本筛选

**状态声明**：本轮未执行工具、未上板、未改源码、未读未给全文；以下只引用给定 R1/R2 回答、`metrics.csv`、`D1-analysis.txt`、既有 docs。新内容均为提案，不是已执行结果。C1 的 R2 源码事实作为本轮硬约束，不翻案。

**本轮总处置**：
- **撤回 TSSC 作为新机制立项**：在现有形式下，slack 准入就是 EDF/LLF 家族的启发式变体（D2-R2-Q-D3-1，`round2/D2.md:85-104`；C2-Q2，`round2/C2.md:35-45`）。
- **撤回 HOL-D 作为新机制立项**：极可能只是普通 VC/PTB/response 槽重命名（C1-QD3-2，`round2/C1.md:99`；自攻，`round2/D3.md:140-151`）。
- **保留为条件备选**：TSSC 只剩“服务成本内生”假设；HOL-D 只剩“当前 N 与普通 VC 都不能绕过的可达等待链”检查。两者找不到独立差异即永久停。
- **最有希望但未成立**：联合撤销双时限契约 + 异步允许集合 oracle。它先要被强简单对手杀死一遍，模型不过不上 RTL/板测。
- **统计口径撤回**：不把“三个 boot”“0.9% 极差”“八模式矩阵”当普适发表/统计门槛（`round2/C2.md:45`；`round2/C1.md:101`；`BRIEF.md:8`）。

## 2. 四类存活问题的最低成本筛选顺序

### 2.1 统一阶梯

- **L0 文献/规范/源码静态核对**：0 板时、0 重编。产物：最近邻差异表、允许集合/契约前提、源码缺口。
- **L1 模型/最小实例**：离线离散事件、有限状态、依赖图。产物：强简单对手是否已覆盖、最小反例轨迹、样本外预测点。
- **L2 软件/仿真**：仅 L1 过门后。无新 BIT 或最小仿真。产物：逐请求时间戳、阶段计数、oracle 对拍。
- **L3 RTL/板测**：仅 L2 过门后。一次最小 BIT/有限运行，不做大矩阵。
- **统计单位预注册**：不以三 boot、0.9% 或八模式矩阵为普适标准；以实际实验单位和测量分辨率决定。

**推荐顺序**：
1. **先做 L0 文献/规范/源码并行只读**：四类都只读，不耗板时。

3. **只有 L1 出现最小反例/样本外预测，才进入 L2 软件/仿真**。
4. **只有 L2 过门，才考虑一次最小 RTL/板测**。不要八模式矩阵，不要三 boot 口号。

## 3. 最有希望的问题：联合撤销双时限契约 + 异步允许集合 oracle

**问题**：共享不可抢占 IOMMU 中，映射撤销与独立 DMA 截止期同时要求有限完成；规范允许某些异步结果集合，能否定义一个声音 oracle 验证“撤销后 safe reuse”，并判断联合准入是否真比强简单规则多出可行域？

**强简单对手**：正确选择性失效 + 静态服务预留 + 每租户在途上限 + 固定优先级 + 最长不可抢占尾段计入预算（`round2/C2.md:116-120`；`round2/C1.md:117`）。如果它在同资源、同安全、同下游有界下满足全部约束，候选应死。

**最小决定性实例/未来实验**：
- **L1 有限状态模型**：2 租户，A 持续 DMA 读/写，V 有截止期；撤销到达后计时包含软件排队、CQ 提交、IOFENCE、PR/PW 排空、设备侧失效。比较强简单对手 vs 候选联合准入。
- **三约束**：撤销完成时限、V 服务时限、A 非零进度。
- **杀判据**：简单对手满足三约束 → 停。若简单对手失败，给一条最小反例轨迹，说明局部保证为何不能推出联合时限。
- **oracle 最小证据**：一条合法重排不报错，一条非法竞态被抓；oracle 前提和声音性说明。若做不到，只保留问题陈述，不立项机制。
- **后续**：只有 L1 有反例，才做一次 L2 官方模型/仿真对拍；只有 L2 过门，才考虑一次最小 RTL/板测。不做大矩阵。

## 4. 一个非传统备选：允许集合驱动的逆评测

不是把 EDF 改叫 slack、把 VC 改叫 HOL-D、把 quota 改叫产权。备选是：

**把规范允许的部分序/允许集合当作工作负载生成器，反向生成最坏合法撤销/到达序列，用来证伪 QoS 声明。**

- **输出**：合法竞态生成器、非法竞态 oracle、可复现反例、覆盖率边界。
- **强简单对手**：随机差分测试 / 官方参考模型逐条相等。
- **最小决定性证据**：oracle 对一条合法重排不报错；对一条越过规范边界的竞态报错；自动找到“完成后仍可访问旧映射”之类最小反例。若随机差分已覆盖，停。
- **与联合撤销共享工作**：不先要求新硬件；可先只读规范/模型。若只能产出工具、不能改变问题定义或发现真反例，则不作为主贡献。
