# 单条B2：普通方法之后还剩什么

B1-STRIPE-COST-1；2026-10-16 JST。root的直接源码推导，AI辅助研究；不是DMA运行、替换仿真或性能测量。源字节/位置见[root原文清单](root-source-manifest.json)，应用逐事件卡见[单条带来源](../stripe-source/findings.md)。

## 1. 固定对象与来源身份

仅HERO mm-large默认256×256、16行条带：s=0,t=0计算B0期间，准备同一次s0所需B2，在t1提交B2。实际B0/B2复用b_ptrs[0]；B1使用b_ptrs[1]。B0 job的ID已经wait完，可以回收；B0数据仍须等t0计算隐式barrier后才释放。准备翻译不允许提前覆盖SPM，也不等于首次物理Ax被接收。

关键身份收紧：main:367–371真正启用copy-based device1，:382–404的SVM device0是if(0)。目标函数的b与host malloc的映射关系未核，不能把b+2S直接写成当前Linux原VA/SID。源码可支持一个明确标注映射/接口假设的研究投影；不要求先有native trace才允许投影，也不把关闭的SVM分支或新投影写成已运行场景。

准备窗口固定为t0显式barrier之后至t0计算隐式barrier之后；b+2S更早已可计算。原代码没有prepare hook。窗口时长、debug发出/完成时刻、普通预热费用、真实页表及IOMMU绑定均unknown。

## 2. 容量上界：不能把六个SPM槽都算成活翻译

在共同条件投影中，仅外部源腿通过同一上下文IOMMU，4KiB leaf，无其他未具名流量。A0/B0已wait，不再为本窗口产生输入搬运；A1/B1可能仍在途。s0没有C外送，t0只写本地C0的一部分。普通B2预热也不写SPM。这里不把本地SPM地址、外围target map或CPU指令偷偷塞入IOTLB集合。

S=16384=4P。设A页内偏移α、B偏移β，则：

`|A1| = 4 + [α ≠ 0]`

`|B1 ∪ B2| = 8 + [β ≠ 0]`

因为B1、B2相邻，不对齐时恰共享一页。所以联合地址集合至多`12+[α≠0]+[β≠0] ≤ 14`；如果跨矩阵出现同key重叠，只会更小。早期逐条5页相加的15是未去重保守上界，紧上界为14。它不是同时必须驻留量、不是miss数，更不是时延。

平台配置16项IOTLB，原件是全关联逐项tag比较、tree-PLRU更新/受mask限制替换。对这个源输入，没有出处要求普通对照必须局限M0的2项protected子分区；不能借旧P/PN参数制造容量不足。一个具备合法pin/替换排除能力的普通对照，最多保留B2的4/5项，仍余12/11项；几何上可容纳其余正常来源。**pin是拟议付费接口，不是当前policy_mask已经实现的功能。**

容量可容纳不保证当前PLRU留存。旧无用条目可以仍在cache，实际插入/命中顺序与替换历史缺失；没有强制容量溢出，不代表绝不发生有用项驱逐。也没有证据证明某次驱逐实际发生、PTE cache未化解重走，或重走影响了最终矩阵完成。不能把这几层命题合成“预热一定足够”或“B1一定有收益”。

## 3. 五项普通方法各自还要付什么

| 方法 | 已有/拟议与本卡能说的范围 | 未知或应收费项 |
| --- | --- | --- |
| 现有debug纯翻译 | InclDbg=1；normal/debug共用TL，normal优先；正常PTW成功填IOTLB，debug另回PPN/状态 | 软件权限/调用、MMIO、CPU、串行服务、窗口内完成与留存；不是免费额外walker |
| PTE cache/可行大页 | 已核DATE2025表明PTE LLC是实际强近邻，页粒度须按同合同提供给双方 | 原论文数字不等于本机残余，cache命中仍不自动消除IOTLB lookup成本 |
| O-PIN | 同付费登记、准确key/owner、最后翻译用途释放；本卡无强制容量超额证据 | 替换排除、满表回退、pin owner/失效/错误/解锁、对其他服务的机会成本；当前未实现 |
| 紧凑O-PAQ-D/局部ATC | 可共享span/context表头，用页偏移索引，不强迫逐页复制通用tag/所有两级字段 | pending/ready/fault与旧fill归属、许可/epoch、索引/读写口、真实采纳路径和错误回退 |
| 正常翻译后的结果缓存 | 可在可信已译PA位置复用，减少重复TL访问；区别于缓存payload数据 | 需新增或证明跨request有效性、key/权限/失效、命中mux；现存TC只保一个当前响应，不是多页future缓存 |

原debug响应只有PPN、fault、PBMT、superpage指示，不是一张带完整未来owner/失效有效期的许可。实际iDMA AT字段固定为untranslated；在当前translated-context通路，仅把src_addr改成查得PA仍会走正常翻译。TL本来有translated语义且检查EN_ATS，不能由InclATS=0推断它完全无这类语义。若另选合法Bare DID/可信物理通路，须明确授权、绑定、切换和撤销费用；本卡未核完整通路，不把它当免费能力或绝对不存在的能力。

## 4. 正向版本与应停止的主张

值得保留的版本是：给一个实际正常、或来源绑定且假设冻结的span，以完整可信结果保存/交接降低部署或服务成本；最简实现可以就是普通PA队列。ICCD2018已发展进度限定纯预取，ATS已分离翻译/后续访问，DATE2025已展示普通PTE cache作用，因此泛称“先译后搬”不能提供论文增量。接口/集成贡献仍可能成立，须有具体残余与完整成本证据。

本卡完成后，**不以“SPM忙、普通预热必丢、需要免费未来描述符”作为该B2实例进入实现的理由**：SPM忙是真的，后两项不是已证事实；实际源码还没有启用所声称的SVA路径。所选未来准备协议可以合法设计，但没有来源证明它相对允许普通方案解决了当前瓶颈。此处停止追加该正例的模型/RTL建设，是投资判断，不是证明B1思想族无价值。

重新进入只需一组能改变结论的具体输入：同一source实例的目标侧地址/leaf/context、准备至消费期间合法请求与缓存服务合同、普通方法后仍有效的残余及其完整后果，或一个同scope实现确有更好完整成本/部署能力。测量或事前冻结的来源投影均可；不必强制native，也不能任意加流量或缩小基线容量制造赢家。
