# R4 论文价值与执行性审查

根协调，不计额外席位。读取完整六份 R3 后，审意义、近邻差异、强基线、成本与泛化，区分能补的证据缺口与候选本身致命问题。

## 本轮必须纠正

- 同 miss 总数不代表同一服务需求，更不能直接叫“非miss成本”。页、层次、到达位置、缓存初态和每次PTE服务时间可不同。A16 N/S 是总计数不足的反例，未定位具体损失。
- A完成率坐标仍是 `A_c/W_V`。`A_c`只是辅助总量，不能在尾表又退回它作为Pareto坐标。共同窗口/在途边界会影响结果，但并不自动构成“窗口伪差”；只有度量定义、采集或外推不成立才判度量问题。
- 固定实际 hit槽/touch/fill trace，在改victim之后不可继续强迫原槽命中和原fill并声称完整反事实miss数。可以验证首个局部差异；长程比较须按逻辑页重新执行hit/miss/fill并明确反馈模型。
- D2 R3第3.2/3.6的“A作业变长就推迟V释放”“V时间增量约等于A作业增量”仍需实际共享依赖，不是从完成驱动自动推出。它不能假定跨流job锁；R2源码已限定burst边界。
- 当前聚合及OPEN/CLOSE快照没有有序事件trace，这个缺口已知。不把“再扫描是否已有trace”作为反复的下一步。快照解码定义源码可查；其存在不会恢复中间次序。最先交付应推进到可运行的局部干预规格/复用现有测试入口，而非再提一张待办表。
- 不设置循环门槛：实物局部证据可能正是确认普通基线为何有效所需；不能要求未观察前已证明全部基线不够。诊断可以廉价先行，方法投入才要意义和强基线门槛。单个强基线在一个点匹配，也不足否定所有有界目标区域；相反不能为了保票不停换目标。
- A1 R3仍把总完成数1:1称“锁步”，并列出二选一解释。这不排除两流在窗口内轮流领先/追上等合法过程；整轮相等不是逐间隔同步。AAAA授权片段也不足证明job锁，须看边界、两方valid/ready、数据返回及资源所有权；AR/AW握手序与完成序可能不同。O1/O2应保留为观察模式而不是排他性根因。固定A就绪时刻并改变mux仲裁若破坏上游依赖，只能是刻意切边的模型，不是合法全系统反事实。

## 审查交付

1. 每个候选：当前可接受的最窄主张、尚缺的关键证据、最近邻真正重叠/待核、不超过两个主要致命风险。
2. 最有希望的一个性能问题（允许无已成立新方法），及为什么值得先花有限成本；避免只为保PN。若不同席排序不同，保留理由。
3. 把下一步收敛成一个具体产物：已有RTL小型测试/模型的最小扩展规格与输出、或另一个能直接改变决策的产物。说明已有哪些内容在R3完成，不要五轮之后仍只计划再写计划。
4. 明确何时才需要BIT编译/短上板；当前只讨论，不执行。成功后的下一门槛和失败后停止的对象要精确，不能把否定一个机制扩大为放弃性能。

不重复已收齐事实、不再进行广泛文献或仓库探索。必要查新限于能改变首选判断的具体原始来源缺口。
