# A4 R2 交叉审核：C4、D4，以及跨方向 D5 查漏

## 候选裁决表

| 候选 | 最强版本（一句话） | 裁决 | 致命 / 可修复 |
|---|---|---|---|
| C4-P1 | 批量 gather 的搬运窗口不按元素数划分，而按"翻译工作集 × 下游可开工的消费组"划分 | **收窄后保留**：只作测量问题，证据不足，不立机制 | 机制新意可能被软件分组、小 tile 加双缓冲吸收，**可修复**；应用门槛未过，**可能致命** |
| D4-P1 | 设备侧散读的吞吐随窗口 K 非单调，存在可被布局移动的最优 K\* | **降级**：并入 C4/A4 的同一测量 | "非单调即新规律"**致命**；作为测量项**可修复** |
| D4-P2 | 用 IOMMU walk 解析应用级 indirection，替代描述符链 | **淘汰** | **致命**：退化为现有 VMM/IOVA 重映射 |
| D5-P1 | 稠密注意力 KV 超订时，调度器免费信号使采样观测净收益 ≤0 | **降级**：接近同义反复 | **致命**：对照对象并非生产实践 |
| D5-P2 | 观测是可争用资源，相位触发的短时观测可省扰动 | **证据不足**：只保留时间预算分支 | 外溢分支依赖未证实的计数器争用，**可修复** |

## (1) 致命问题

**D4-P1：非单调不等于新规律。**

- EVIDENCE：D4 主张"K 增大因 IOTLB/PTW 压力而降低吞吐"（D4.md:29）。
- EVIDENCE：DX100 按索引原序翻译（A4.md:20）。
- INFERENCE：窗口超过缓存容量后出现回撤，是经典的工作集/抖动现象，与 TLB reach 结构相同。只要窗口内先按虚拟页排序再翻译，K 增大反而提高每页复用，曲线可能恢复单调。所谓 K\* 很可能只是"朴素原序翻译"的产物，而不是布局与翻译之间的新约束。
- EVIDENCE：Milk §5.2 已按 TLB reach 和 cache 容量约束临时容器（C4-source-notes.md:12）。因此"在给定材料里没有先例"（D4.md:20）不成立。
- 停止条件方向错误：
  - INFERENCE：D4 写的是"若在大页/连续布局下单调且差距 <5% 则证伪"（D4.md:36）。但大页正是预期不出现非单调的条件，这个检验无法否证主张。
  - RECOMMENDATION：应改为在 4 KiB 布局下比较"原序"与"页排序"两条 K 曲线。
- 成本不能相加：
  - INFERENCE：D4 的因果链（D4.md:32）把 DRAM 收益与翻译损失当作对冲。在流水化引擎中，PTW 与数据读取重叠，只有当串行 PTW 时间超过数据时间时才会回撤，即瓶颈是 max 而非 sum。
  - EVIDENCE：C4 已正确写成 max 下界（C4.md:72）。
- 平台实验不可行：
  - INFERENCE：iDMA 本身没有硬件重排窗口。"K 从 16 扫到 64K"实际只能是 CPU 预排批次，测到的是软件策略，不是窗口机制。
  - EVIDENCE：PRIMARY_CHECKS 说明同类 CVA6 FPGA 基线仅 4 个 IOTLB 项，加入 LLC 后翻译开销大幅下降（PRIMARY_CHECKS.md:17-18）。
  - ASSUMPTION：Genesys2 平台是否有共享 LLC 或 PTW cache，材料中缺失。若没有，暴露出的回撤会被高估。
- 应用不真实：
  - EVIDENCE：D4 自认 LLM 场景常见单一池或大页（D4.md:32）。
  - EVIDENCE：PagedAttention 的强基线是 2 RTT（ROOT_REVIEW.md:18）。
  - INFERENCE：hash-join bucket chaining 部分属于真串行链，D4 混入了不同类别。

**D4-P2：已被现有方案覆盖。**

- EVIDENCE：D4 自认叶 PTE 只存 PPN 与权限，不能存任意指针（D4.md:58）。
- INFERENCE：把"逻辑块→物理块"编码进页表，正是 vAttention 用 VMM 取代 block table 的思路（D5.md:73），也是普通 IOVA 映射把离散物理页映射成连续设备地址的用法。剩下的成本是 map/unmap 与失效，这已是 rIOMMU 和 IOMMU Scalably 的主题（research-landscape:88-89）。
- INFERENCE：深度 ≥2 的一般指针结构无法表示；若改 PTE 语义，又会破坏权限与隔离的分层。

**D5-P1：对照对象并非生产实践。**

- INFERENCE：稠密 decode 每步读取活跃请求的全部 KV。因此页级 LRU 必然退化为请求级近期性，"免费信号不劣于采样"几乎由定义成立，没有信息量。
- EVIDENCE：vLLM 已经用调度器驱动 swap（D5.md:109）。
- ASSUMPTION：生产服务并不靠 UVM 驱逐管理 KV，所以对手是虚设的。
- INFERENCE：在稀疏区，InfiniGen、H2O 一类方法本身就使用注意力分数这类语义信号。两端都被覆盖。

**跨提案的通病：把单次实测当成上界。**

- EVIDENCE：D5 把 ObservUVM 的 40–78% fault 下降当作"收益上界"（D5.md:118）。
- EVIDENCE：我自己的 R1 写了"上限约 8 倍"（A4.md:67）。
- INFERENCE：有限 trace 或他人负载上的最大值都不是硬上界。

## (2) 值得做的改进

- **C4-P1**
  - EVIDENCE：C4 已把 DX100 小 tile、Milk、MMU-aware DMA 列为强对手（C4.md:49-54），并以 AMReX arena 作反证（C4.md:37）。这是三份提案中基线最诚实的一份。
  - RECOMMENDATION：把"消费组早开工"与"翻译分组"拆成两个独立门槛。前者本质上是任务图或数据流调度，属于旧题，必须先证明消费组信息在普通运行时不可见，才有接口新意。
  - RECOMMENDATION：15% 的筛选门槛必须在"暖页表 + LLC + 页排序"之后计算。
- **D5-P2**
  - EVIDENCE：ObservUVM 已有自适应调整每区域采样页数的机制（D5.md:147）。
  - RECOMMENDATION：时间预算分支必须与该机制比较，而不是与固定持续观测比较。
  - INFERENCE：2.4% 与 1.8% 两项开销（D5.md:171）不能直接相加。
- **跨方向查漏**
  - INFERENCE：D5 唯一与本方向相关的 FPGA 子项，是多上下文下 map/unmap + IOTINVAL 的尾时延（D5.md:196）。它与 A4/C4 的"阶段间换映射"共享同一测量，可以合并设计。

## (3) 首个判别（零硬件，只做一次，覆盖 A4、C4、D4-P1）

RECOMMENDATION：

1. **应用门槛（C4.md:90 的 A 步）。** 在一个真实阶段中记录分配与映射粒度。若 gather 区域稳定落在大页或池中，A4、C4、D4-P1 一并停止。
2. **离线 trace 统计。** 对 DX100 artifact 的索引流（A4.md:74；trace 是否随 artifact 公开，待核）逐 tile 统计：
   - 不同页数 U、不同叶 PTE 线数、不同数据线数 L；
   - 在 C ∈ {4, 32, 256} 下，原序与页排序两种顺序的 LRU 未命中；
   - 叶 PTE 分"命中 LLC"与"未命中"两档建模；
   - 同时画出两种顺序下的 K 曲线。
3. **判据。**
   - 页排序曲线单调 → D4-P1 的 K\* 被否证。
   - 页排序且暖 PTE 后，翻译线数 / 数据线数 < 5–10% → A4、C4 的翻译分支停止。
   - 以上阈值是筛选门槛，不是测量结果。
4. **D5。** 对 D5-P1，先用一条稠密 decode trace 确认页级与请求级排序是否等价；若等价即停止。

## (4) 审核停止条件

- 第 (3) 步在任一真实应用上都留不下超过阈值的剩余翻译成本，或找不到被迫使用 4 KiB 映射的批量间接 DMA 应用时，本方向三份提案均终止。不再为现有板子制造碎片。
- 若有剩余空间，先补读 Neighborhood-Aware Translation、Terminus 与 Milk 的全文，再讨论机制。

## 本席 R1 需要撤回或修改的主张

- **撤回**"DX100 首次让整 tile 在翻译前可见"（A4.md:30）。Milk 式软件早已看见整个批次并按 TLB reach 分组（C4-source-notes.md:11-12），硬件页排序的独立贡献仅剩"位于 IOMMU 前"这一点，而该点尚无应用证据。
- **撤回**"恢复至少一半差距"（A4.md:3）与"叶线上限约 8 倍"（A4.md:67）。两者都无依据，也不是硬上界。
- **修改** FPGA 判别（A4.md:81-86）。必须加入暖 PTW 与 LLC 条件（PRIMARY_CHECKS.md:17-18）。"4 KiB 随机序与 2 MiB 差距 <15%"在无 LLC 的低端平台上会夸大问题；平台是否有 LLC 待核。
- **修改**"tile 越大排空窗口越长"（A4.md:61）。这是普通 device TLB 的义务，不是新成本。应采纳 C4 的收窄：读阶段内映射稳定，阶段间允许换映射（C4.md:33）。
- **待核**：D4 引用的 DX100 大页行号（449-452）与我引用的（434-446）不一致，需核对原文。
