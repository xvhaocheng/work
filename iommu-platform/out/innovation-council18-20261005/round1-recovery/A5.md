### 1. 对原文的更正

**更正一：原文混淆了三个层级。**
- [INFERENCE] 主张中的"粒度错配"实际上涉及三个不同的粒度：
  - (a) 虚拟内存映射粒度，即 vAttention 的页组，归驱动和 VMM 管；
  - (b) 驻留与分层决策粒度，归 serving 运行时管；
  - (c) 注意力内核的访问粒度。
- HBM 浪费只与 (b) 有关。原主张第二条"vAttention 式布局的内核收益趋于零"（A5.md:106）属于 (c)。它既不能从 (b) 推出，而且 vAttention 的收益本来就主要在 prefill（原文自述 A5.md:84）。**此条撤回。**
- 本候选与 IOMMU 或翻译硬件没有直接因果关系，是应用运行时层面的问题，只能挂靠地图卡点 1"粒度不一致"（research-landscape-20261005.md:35）。

**更正二："信息由模型免费给出"（A5.md:93）是把假设当成了事实。**
- [INFERENCE] 运行时免费知道的只是"哪些 token 存在、属于哪个请求"。它并不知道"下一步哪些 token 重要"。
- 精确的 token 级 top-k 需要先对全部 key 打分，这意味着 K 必须常驻或可读，或者改用近似元数据。所以"选择信息"本身是有代价的观测。
- 这同时收窄了 §0 遗漏一（A5.md:36-42）：筛选规则仍然成立，但 LLM 场景并不能自动豁免观测成本。

**更正三：其他措辞收窄。**
- "必然要向主存分层"（A5.md:68）应改为"分层是选项之一"。并列的选项还有多卡切分、KV 量化和丢弃式压缩。
- 浪费因子公式（A5.md:105）只是单游程情形下的上界。真实指标应定义为"触及页数 × 页 token 数 / 选中 token 数"。

**更正四：ObservUVM 细化需要收窄。**
- [EVIDENCE] 区域在一次通知后确实不再可观测（observuvm2026.txt:384-386）。但策略每次事件都会重新挑选观测候选（observuvm2026.txt:522-528），采样数也会自适应调整（observuvm2026.txt:514-522）。

### 2. 第 4 节续：回取侧的放大效应与代价

- **粒度对比。** [ASSUMPTION] 设 Yi-6B 为 32 层，则每 token 每层 KV 约 64KB/32 ≈ 2KB（若 K、V 分存，则各约 1KB）。[INFERENCE] 这与原文转述的"64KB 页组含 32–128 token"的下端吻合，但该数字未复核。
- **两种回取方式的代价。**
  - 按 token 回取：每步每层发出大量约 2KB 的 DMA。小传输的链路效率较低，这是推断，未测。
  - 按页组回取：为少数选中 token 搬整页，带宽被放大。
- **其他不可隐藏的代价。** 选择元数据（每块的摘要或代表向量）、映射调用、紧缩拷贝所耗的 HBM 带宽，以及精度损失。这些都必须与"HBM 有效容量提升"放在同一账本里比较。
- **跨域旁证。** [EVIDENCE] OASIS 在 2MB 页下会把私有对象挤成共享对象，收益随之下降（oasis2025.clean.txt:897-905）。这说明粗粒度会扭曲语义分类，可作为机制层面的旁证，但不能证明 LLM 场景成立。
- **本候选押注的方向。** [EVIDENCE] ObservUVM 测得超过 90% 的 2MB 区域在被驱逐前所有 64KB 页都被访问过（observuvm2026.txt:367-370）。[INFERENCE] 本候选押注的恰好是相反的情形：页内稀疏。这正是需要验证的地方。

### 3. 最可能致命的反例

1. **块粒度选择已经吸收了错配。** [ASSUMPTION，仅凭记忆] 若按页或块打分的稀疏解码在相同字节预算下精度接近 token 级选择，那么选择粒度可以直接对齐驻留粒度，错配问题不存在。
2. **时间局部性强。** 若相邻解码步的选中集合高度重叠，驻留集就稳定，细粒度的代价可以被摊薄。
3. **多头与 GQA 取并集后变稠密。** 若一个页组存放某 token 所有头的 KV，那么各头选择取并集后会显著变稠密，错配随之减弱。
4. **强互连使分层可以直接远读。** 在 CPU-GPU 强互连平台上直接远读选中的 KV，可能比管理驻留更简单。

### 4. 最强普通方案（须在相同 HBM 预算和相同精度下比较）

- (a) 16-token 分块，加块级选择，加按分数或 LRU 的块换出（vLLM/PagedAttention 路线）。
- (b) 每步把选中 token 收集、紧缩到连续暂存区。
- (c) 不做分层：KV 量化、多卡切分。
- (d) 文献中的块级元数据选择方法（待核）。

### 5. 低成本判别实验与停止条件

**[RECOMMENDATION] 第一步：纯离线 trace 分析，不需要 FPGA，也不改系统。**
- 选一个开源长上下文模型，在全注意力 decode 时记录每步、每层、每 KV 头的 top-k 索引（或累计注意力质量达到阈值的集合）。
- 计算以下指标：
  - (i) 选中游程长度的分布；
  - (ii) 页组大小 G∈{16, 32, 64, 128, 1024} 时的覆盖放大比 R(G)；
  - (iii) 相邻步触及页集合的 Jaccard 相似度；
  - (iv) 头内单独计算与同层头并集两种口径下 R(G) 的差异。
- 同时让协调者完成文献核查：块级与 token 级选择在等预算下的精度对比是否已有报告。

**停止条件。** [ASSUMPTION：阈值为本席设定，需在审核中商定] 满足以下任一条即淘汰本候选：
- 头并集口径下 R(16) ≤ 1.5，且 R(64) ≤ 2.5；
- Jaccard ≥ 0.8；
- 文献已给出等价的定量边界。

**第二步（仅在第一步通过后）。** 在 GPU 上实测上述三种策略的代价曲线。
