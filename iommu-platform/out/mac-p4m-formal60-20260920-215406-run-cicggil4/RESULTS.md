## 4. 说明

- 以上为描述性统计（中位/最小/最大/均值/样本标准差/CV），不做显著性检验，不做因果结论。
- CV 以分数记录（= sd/mean）；表格表头标注 CV(分数)，转百分比时乘 100。
- 所有有效样本均保留并列出；未剔除离群点，未做任何事后筛选或重跑。
- 数学上无定义的字段（缺采集、分母为 0、窗口 <= 0）记为 null，表中显示为 `-`，原因见 flags；仅忽略数学上无定义的值，n_missing 记录被忽略数。
- `capture=partial/missing` 表示该 trial 的 CLI JSON 未完整捕获；原始行区间见 captures.json 的 raw_source，原文见 raw_stdout；records.json 只保留成功解析为 dict 的 CLI JSON。
- trial 上限 60；未运行/未采集的剩余 trial 按剩余数列出，不记为已完成。
- 软件（startup/irq-pair）A 域与硬件观察窗 A 域是两个分开的域：`startup_domain.a_id` 与 `hw_a_domain.opening_inflight_id` 不做等价比较。
- V 速率 = 16 MiB（4096 x 4096 B）/ (`p4m.hardware_window_ns` / 1e9)，即 bytes/(ns/1e9)，不是 bytes/ns；A 窗口速率是 P4M 观察窗内完成速率，不是 AXI/总线吞吐。
- A 整程 HPM 取 `result.aggressor.active_cycles`、`iotlb_miss`、`s1_ptw`、`s2_ptw`（整程，与窗口无关）。
- `batch_time.done_to_read_cycles` 取 `part=time` 行的 `done_to_read` 计数；`batch_time.cycles` 是同一行的硬件 cycles，可与 `p4m.cycles` 对照。
- 内核相关读数基于固定 50 MHz 假设；本报告只是只读后处理，不构成独立验收。
