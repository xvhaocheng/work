Mac 部署说明：fullstats 全量搬运分组统计（cost-fullstats）

状态：软件与FPGA完整构建、主机测试和交付核对通过；尚未上板（0/21）。版本与哈希见 SHA256SUMS、DELIVERY.json。
FPGA 在 Mac。Dell 不接板。本轮必须同时使用新的 ariane_xilinx.bit 和新的 fw_payload.bin；只换一个不算完成。
硬件：CVA6 0dc5e333；profile 50MHz DS50/50；fullstats magic D00=IDMAAGG1。
内核：6.5.0-rc2-00092-g5853e425caf8（以 DELIVERY.json 与板上 uname 核对）。

1. Mac 解压后在交付目录执行 shasum -a 256 -c SHA256SUMS。
2. 用既有 Mac SD/SPI 流程安装本包。现有流程是旧说明，不要假设物理 SD 已准备；先确认卡/镜像/目标。安装新的 fw_payload.bin，并配置同一交付包中的新 ariane_xilinx.bit。新 BIT 和新 payload 二者都必需；若断电丢失配置，按既有方式恢复同一个新 BIT。
3. 启动后确认内核：6.5.0-rc2-00092-g5853e425caf8。保存 fresh boot 的 dmesg 和 taint 原样记录；taint 0 不等于无 warning，不得写成 warning-free。
4. 在板上只执行一次，OUTDIR 必须不存在：
   platform-research cost-fullstats /tmp/research-fullstats-01
   该命令应自动先跑 3 个短 cost 用例，再跑 18 个主 cost 用例，共 21 项。不要手工另跑 CLI，不要做冻结 21 项之外的额外试验。
   --require-fullstats 由交付 runner 自动追加到每次 CLI；操作者不要手工补 flag。本包已验证21项筛选、实参记录和首错停止。
   短：64 transfers、warmup 8；主：4096 transfers、warmup 256；每次 4KiB；V=DMA0，A=DMA1；gap 由冻结计划给出。
5. 首错即停：不自动重跑、不剔除、不删除、保留现场。旧 E2 不重跑；旧 84 不重跑；不与旧结果合并，不把新 Solo 与旧 non-Solo 拼接。初次上板结果不是方法 M 收益。不裁剪 Linux，不另改 bootrom/SD 分区布局/实验 RTL，不引入新 JTAG 启动流程；不要 halt/reset/写内存打断运行中的 Linux。
6. Mac 回传整个 /tmp/research-fullstats-01 和 UART 原始日志，并记录本次 fresh boot、kernel、BIT/payload 哈希（引用 SHA256SUMS/DELIVERY.json，不另造哈希）、argv、cases、dmesg、frozen plan 副本和原始退出码。若停止，保留 STOPPED.txt。
全部在线通过应为 cases=21 total=21 final_exit=0；仍需离线核查。

离线分析（必须新目录，独立新版本，不合并旧结果）：
INPUTDIR="/绝对路径/research-fullstats-01"
NEW_ANALYSIS_DIR="/绝对路径/analysis-fullstats-01"
[ ! -e "$NEW_ANALYSIS_DIR" ] || exit 2
python3 analysis/research_results.py cost-fullstats "$INPUTDIR" --output "$NEW_ANALYSIS_DIR"

INPUTDIR 应包含 runner 的 plan.copy.tsv、plan.data.tsv、plan.selected.tsv、params.txt、argv.tsv、cases.tsv、taint.txt、uname.before/after、dmesg.raw/err、每个 <case>.json/.err/.exit/.cmd/.dmesg.before/.after；若停止还含 STOPPED.txt。NEW_ANALYSIS_DIR 是独立新版本输出目录，不得把旧 84/E2 JSON 合入，也不得覆盖 INPUTDIR。

分析口径：fullstats 模式期望 21 项并强制全量字段。分组 0..4 是 requests=4 且 IOTLB miss=0..4，组5 是其他所有组合且不得静默丢弃。均值只能由 sum/count 得到；不能从这些字段推导中位数或分位数；没有原始全量记录不宣称总体中位。请求/miss 只有有限类型覆盖，没有 DDT/PDT/PTW 级别细分，不宣称完整类型加权基线。三块主实验是工程重复，不保证统计显著；组内搬运不是板级重复。报告全量均值/范围与旧抽样均值/范围、分组覆盖数；抽样中位与总体均值不是同一量。
