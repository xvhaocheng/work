# 硬件批量版交付

2026-09-16：RTL、驱动和程序已实现；定向回归通过，软件/FPGA构建均退出0。新版尚未上板，无新性能结论。按用户要求只保存成功日志，未另外审查时序报告。

## 使用哪些文件

- `ariane_xilinx.bit`：通过已有Mac/JTAG流程配置FPGA。
- `fw_payload.bin`：内核00082及新版程序，按已验证的SD原始分区流程更新；不是把本目录所有文件复制到卡。
- `idma_experiment`：独立程序副本；启动镜像中已包含。
- `E4_BATCH.md`：接口、观测口径、实验逻辑与短测命令。
- `delivery.json`、两份manifest、`sources.lock.json`、`SHA256SUMS`：版本及产物记录。

需要同时更新新BIT和SD软件。用 `--batch` 选择硬件批量供给；不加它仍走原软件逐项轮询/补交。新模式保持CPU轮询整批完成，4KiB之间由硬件接续。

## 第一次上板

先做8项、无预热的短Solo，连续两次相同配置，换DMA角色重复；再8页/8项Solo检查地址序列、双角色A1/A8及8/64项校准。每次保存JSON、退出码及同seq的三条 `idma_batch_obs` 内核日志，异常即停。具体命令和有效性条件见本目录 `E4_BATCH.md`。

确认正确性、计数、A覆盖和实际请求重叠后，再做4096项正式窗口。此处没有执行刷卡、JTAG或实板实验；旧E1/E4产物和原模式保留。

软件构建顶层为e47b48e，FPGA为3198fef：两者差别来自重复批次计数的RTL修正，Linux均为b7979a1a06ac，软件无需因此重编。CVA6为7ed43840cab2。完整版本和文件哈希见delivery.json。时钟/CDC/IO约束的原待办保留。
