# 基础 rootfs 来源

`rootfs-base.cpio` 是迁移时从旧工程保存的 2026-07-11 基础镜像。其内容包含 BusyBox 和旧用户空间；本次没有从源码重建全部用户空间，也没有对其中每个工具补齐源码来源。

它作为固定构建输入保存在仓库中，使内核和新 benchmark 的重新打包不依赖旧目录。`scripts/rootfs.py` 每次剔除旧 idma 程序并插入新编译程序，保留设备节点与其他基础内容。

当前可复现范围是“从这个固定基础镜像构建新的 rootfs”，不是“从所有用户空间源代码重建 rootfs”。若之后对外发布完整镜像，需要整理各工具来源、许可证及对应源码材料；这不影响本地继续实验。
