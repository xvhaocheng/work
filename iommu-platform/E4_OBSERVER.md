## 已实现什么

保留原来的同CPU轮询、补交次序、每路一个软件未确认完成描述符、缓存同步、正确性校验和排空规则。新模块仅观察信号，不输出DMA/AXI通路的背压或控制；不在每次轮询中额外读计时寄存器。

- H：前端分配任务ID到该任务完成退休；包括前端、内部排队、翻译、搬运。
- P：完成退休到第一次被接受且返回该ID的DONE寄存器读取；不是CPU精确发现时间。
- R：上述读取到下个任务分配ID；最后一个任务之后不再累计R。
- P/R也可能包含控制寄存器访问通路的等待，不能全部称为纯CPU执行时间。初版先区分DMA已发出后的硬件时间与供给/完成观察路径；需要进一步分开CPU指令和控制总线时，再据结果追加对应观测。
- 保存三段总和/最大值、任务计数，并校验H+P+R等于同一硬件窗口周期数。
- 在四路DMA的mux前观察地址提出/受理及RLAST/B返回，按本次V/A角色统计无请求、仅V、仅A、两者重叠的周期和AR/AW等待；同时统计mux后公共入口地址受理/等待。每路AXI ID应为0，异常ID或在途计数错误会使观测无效。
- 在途跟踪跨预热和ARM持续运行；首个V任务分配ID时开启累计，末个对应DONE读取后冻结。窗口首末记录读/写在途存量，用于“期初+受理=完成+期末”检查；末尾A排空不改冻结结果。

采样累计采用从开始边沿之后到关闭边沿的周期约定；开始边沿发生的AXI受理/返回计入期初存量，不重复计入窗口流量。这是明确的硬件观测边界，不与非原子HPM快照假装完全重合。

## 开关与输出

内核参数默认关闭，原RUN ioctl、CLI参数及JSON布局保持。新硬件的观测入口位于DMA0控制窗口，驱动检查完整标识/版本；明确开启但缺少硬件时返回EOPNOTSUPP，不把不存在的观测读成零。

在**新版本 FPGA Linux**中，空闲时设置：

```sh
cat /sys/module/idma/parameters/observe
echo 1 > /sys/module/idma/parameters/observe
platform-timeout 120 idma_experiment --device /dev/idma0 \
  --aggressor none --victim-pages 1 --chunk 4096 \
  --transfers 8 --warmup 32 --timeout-ms 10000
rc=$?
echo "E4 short exit=$rc"
dmesg | tail -80
```

每次调用捕获开关一次，执行中修改开关不会取消DMA或改变当前观测。用 `echo 0 > /sys/module/idma/parameters/observe` 关闭；关闭时驱动不访问观测寄存器。

正常结果在安全排空/校验后以三条 `idma_obs` 内核记录输出，具有相同 `seq`：

| part | 字段 |
|---|---|
| time | valid/status、V/A DID、cycles、h/p/r、各段max、issued/done/polled |
| axi_v | neither/v_only/a_only/both、V的ar/aw/rlast/b/ar_wait/aw_wait、start/end |
| axi_a | A对应字段和start/end、公共入口shared_ar/aw及等待 |

`start/end` 高16位为读在途数量，低16位为写在途数量；当前每方向8位跟踪。`a_did=4294967295` 表示Solo，无A统计。所有时间均为硬件周期，按本版50MHz换算时每周期20ns。三个part必须全部保存并与本次JSON配对；分行是为避免内核单条日志截断，没有热循环逐项打印。异常路径在尝试排空后停止观测并输出无效记录；若DMA未能排空，保持原quarantine及缓冲保留，不借观测去取消硬件或触碰缓冲。非零原实验错误优先保留；观测自身无效在正常实验返回路径上变为EIO，不能作为性能PASS。

第一轮仅执行短试次和观测校准，确认计数、恒等式、内核状态及开关影响后，再按实验卡做36条观测开销样本和60条主样本。不要在旧BIT上开启后继续忽略错误。新版本上板步骤/实际哈希见 [交付README](out/e4-observer-20260916/delivery/README.md)。

板上短试次还要人工确认：默认拷贝的V确有AR/AW受理与RLAST/B返回，计数非零；V的期初/期末在途应已清空，A跨边界存量按守恒解释；Solo的A统计为零。用8次和64次V任务核对硬件窗口周期与软件耗时的量级：按50MHz换算，硬件窗口应位于软件计时边界内部（允许计时量化），端点差不能冒充逐任务开销。若这些检查不成立，先查观测接线/时钟/边界，不进入主矩阵。一次共跑的重叠周期为零本身是有效观测，不作为必须“调到非零”的通过条件。

## 硬件接口 v1

DMA0基址 `0x50000000`；只通过上述驱动管理，不在实验进行中用其他进程读写控制寄存器。

| 偏移 | 内容 |
|---|---|
| 0x58 | 只读标识 `0x49444d414f425301` |
| 0x60 | 写1为ARM，并在[9:8]指定V端口、[17:16]指定A、bit24指定有A；写2只中止观测；写4清除非活动会话状态。读bit0=ARMED、bit1=active、bit2=frozen、高32位错误 |
| 0x68 | 非活动时写V目标任务数，1～2^32 |
| 0x70 | 写结果索引0～33 |
| 0x78 | 读所选冻结计数 |

错误高32位：bit0非法控制，bit1任务序列/ID，bit2累计溢出，bit3AXI在途或ID异常，bit4观测中止。在途异常是从复位持续跟踪的粘性错误，不用ARM把它隐藏。寄存器控制写入要求完整64位字节使能；正常64位访问由现有AXI→reg通路提供。

结果索引依次为：0窗口周期；1～3 H/P/R总和；4～6 H/P/R最大值；7～9 issued/done/polled；10～13 neither/v_only/a_only/both；14～19 V的ar/aw/rlast/b/ar_wait/aw_wait；20～25 A对应字段；26～29公共入口ar/aw受理及等待；30/31 V/A期初在途；32/33 V/A期末在途。只读字段不得写入。
