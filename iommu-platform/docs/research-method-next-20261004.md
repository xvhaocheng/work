## 3. 收益判断与筛选规则

- 关键收益判断不能写成“赢任一弱对照即成功”。
- 公平规则沿用报告定义：V 两侧各组中位速率均需 >= 目标（本轮固定 170）；|medianL - medianR| / mean(medians) <= 5%；每 run E23/E20 不足比例的组均值差 <= 10 个百分点，且每 run 有效完整窗口 > 0；A 均值百分比 =（组均值方法 - 组均值基线）/ 组均值基线，不是中位数之比；CI 基于配对 run 差值重采样，单独报告，仅描述，不作显著性判断；5% 为工程参考阈值，不是统计保证。
- 本节不修改既有 462 项接受判据。
- 强对照选择：每个启动、每个方向，在 p1/p2/p3/p4 中挑满足对 p5 保护匹配且 A 均值最高者，作为“当前最有竞争力的对照”。这是挑强基线，不是挑软基线。
- 预定 p5 对 p1、p2、p3、p4 逐一对照全公开，不匹配不掩盖；每个启动都披露该对照身份，并披露其余对照及不匹配原因。
- 同方向两次启动均匹配，且 p5 相对此对照 A 增益 >= 5%，才算值得后续追机制的窄条件工程信号。
- 必须 2 个方向皆成立，才谈跨方向。
- 不存在匹配可行的对照时，结论为证据不足，不是成功。
- p5 vs p6 是反转复现问题，与简单对照主问题分开。fixedgap 只作参照，且包含不匹配情况。
- n3、启动、方向只作工程判断，不作显著性判断。
- 报告逐 run 配对差、全部 CI、最长 V active 无完成、预算等辅助量。两个启动分别报告，不可只给合并正值。
- 主张与筛选规则提前冻结；该 88 是看过旧数据后的复核，不叫全新盲测。
