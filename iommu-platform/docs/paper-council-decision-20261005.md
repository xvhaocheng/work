# 六席五轮讨论：论文方向与下一步决定

日期：2026-10-05。状态：**讨论完成，研究计划尚未实施；用户质疑转向依据后，根 Codex 修订研究优先级。** 原始五轮答复保留，不新增讨论轮数或实验结论。

## 决定

**继续以多 DMA 共享 IOMMU 的性能干扰与有效缓解为研究主线。** 已有 E3 机制证据和当前 172 数据为其提供直接实验基础；下一步优先解释 PN 退化及发送节奏改变结果的现象，明确共享翻译、数据路径与闭环供给之间可区分的预测，再选择最小对照。现有 P/N/PN 是可用的实验工具和基线，不是已经成立的论文方法，也不限制后续机制、负载或实验框架。

**闭环供给对架构排序的影响，是性能主线内要检验的解释之一。** 先使用现有数据做有明确适用范围的回溯诊断，不能只凭拟合或残差归因，也不能在尚无可区分预测时安排大矩阵。

备选探索为 **DMA 内存安全复用的跨接口约定**。它尚无新的漏洞或方法证据，不因第一步可只读就优先取代性能主线。只有性能研究遇到明确、无法在合理范围内解决的阻碍，或新证据显示接口问题有独立实质贡献时，才重新比较投入优先级。

当前没有候选达到正式论文主线的证据门槛。这不证明该领域无法发表，而是本次提出的新机制、验证器和评测主张尚未证明超越强简单对手的差异。不能把六方意见一致当作创新证据。

这里的“未过门”指具体论文贡献尚未成立，不等于应放弃性能研究领域。先前把接口研究排为首选，是根 Codex 的优先级判断；它没有证明接口路线更容易、价值更高或成功机会更大，本次明确纠正。

## 五轮讨论为何不构成转向依据

普通优先级、RR、交错 walker、信用借用以及带版本的请求记账器，已经能解释或覆盖当前多项提案的小例子。已有工作也覆盖了翻译允许行为、关系模型与测试生成。官方参考模型已有 PR/PW 全局可见性同步回调，不能将“不接这个回调”的弱比较对象当作现有方法。[官方参考模型](https://raw.githubusercontent.com/riscv-non-isa/riscv-iommu/main/iommu_ref_model/README.md)、[TransForm](https://arxiv.org/pdf/2008.03578)、[Arm relaxed virtual memory](https://www.cl.cam.ac.uk/~pes20/RelaxedVM-Arm/RelaxedVM-Arm-esop2022.pdf)

这些质疑压低了具体提案的创新主张，却没有解释全部性能现象，也没有证明性能方向缺少可研究问题。将它们推广为“应先转向接口研究”缺少对两条路线证据、成本与贡献潜力的充分比较。

接口候选仍保留这个问题：**抽象的完成要求，如何由真实硬件接口兑现？** RISC-V 规范区分已被 IOMMU 处理的访问与尚未到达的请求；PR/PW 要求的全局排序点也不能直接等同于某个未经论证的总线响应。[固定版规范](https://docs.riscv.org/reference/iommu/v20260222/iommu_in_memory_queues.html)

本地 `rv_iommu_cq_handler.sv:362` 的 PR/PW TODO 是已知能力边界，不能直接当成可利用漏洞或新颖性证据，也不构成放弃性能研究的理由。

## 公平比较和关键修订

验证方法的最低比较对象是：**官方参考模型＋实际同步回调＋普通逐请求/映射版本记账器**。不能让候选看内部信号、对手只看软件日志。额外观测或同步可以成为方案，但必须明确计入接口和成本。

若同一观察结果既能来自合法执行，也能来自非法执行，正确结论是“信息不足”。新算法不能凭同样的缺失信息猜出真值；应寻找可验证的新增观测或同步条件。另一方面，能用记账器表达不意味着接口知识永远没有论文价值：要检验的是新知识、必要性和实际后果，而非程序能否编码它。

性能主线的既有数据分析只能称**回溯诊断**：172 条都已看过，不是真正未见数据的预注册确认。模型需明确服务成本来源和适用负载，不能用全命中负载的一种耗时硬外推其他工作集，也不能逐格自由拟合后声称预测成功。共同窗口的 `A 完成量 / 窗口周期` 有效；窗外可变尾段另列。单组噪声极差不是通用阈值。拟合好不证明机制，拟合差不定位根因。

不预先认定 non-bufferable 写、有序读、屏障或端点确认一定足够：这是 Claude 提出的候选比较项，协议与平台条件仍待核实。也不使用没有服务/背压界的 `k×burst` 时间上界，不缩小现有全局 fence 的规范义务。

## 当前不继续投入的提案

P/N/PN 组合作为既定创新、普通 hit-under-miss、slack 排序改名、队列/响应槽改名、机会产权账本、普通单值差分验证、用大页把四个 AXI burst 直接变成一个，以及尚无强反例的前置归属/冷 walk 切换/联合双时限提案，均不进入硬件立项。

只有新的真实需求、正确可达的反例或可量化差异才能重开；换名字、增加讨论轮数或补大矩阵均不算证据。
