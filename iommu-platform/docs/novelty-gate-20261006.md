# 实现前创新审查：页感知提交与配置选择

日期：2026-10-06。用户要求进入工作前先查验是否触及研究边界。本轮执行文献/源码/已有结果审查，不执行新实现、实验、编译或上板。

**裁定：当前 A“页工作集感知 DMA 提交”和 B“共享 IOMMU 配置选择”的宽泛表述，均未通过进入机制实现的立题预审。** 它们可以保留为研究问题，但不能继续按“已发现创新、只差实现”推进。前一轮平台可行性成立，不构成新颖性依据。此结论不是证明任何具体改进都不可能发表。

不要求首篇论文颠覆整个领域。一个新约束下有用、可解释、可复现的增量即可作为贡献候选。问题在于当前尚未明确这个增量，而不是目标期刊必须很高。预审也不要求先拿到完整硬件收益；需要先有可核查的前作差异、真实问题和可证伪预测，再允许最低成本的概念验证。收益和完整贡献最后仍须实验确认。

## 3. 新近前沿也在约束宽泛叙述

- [Dead on Arrival v2，2026-06-02预印本](https://arxiv.org/html/2606.00486v2)已讨论相近miss统计下，页共享结构和同一次walk解除多少等待者会造成不同收益，并用驱逐历史保护条目。其“miss统计不足、需额外结构信息”的研究形态与我们的宽泛动机邻近。它不是源端DMA限速，所用GPU/MSHR机制也不能直接搬作本平台事实；当前按预印本处理，不称正式接收。
- [CounterPoint，ASPLOS 2026](https://cs.stanford.edu/~trippel/pubs/lindsay_ASPLOS26.pdf)用硬件计数器与模型约束检验/修正微架构假设，案例涉及CPU地址翻译。B若只说“增加观测、找到计数和性能不一致”，不足以体现方法增量；CounterPoint本身也不是在线IOMMU配置选择器。
- DWS/HPCA2021已有walker分配与非抢占窃取；CLAP/MICRO2025已有依据chiplet局部性选择映射粒度。它们约束泛化的资源/局部性管理主张，但不等于我们的提交动作；CLAP不是预取器。详见[完整证据及修订](../out/novelty-gate-20261006/README.md)。

联网定向检索截止2026-10-06，覆盖源端提交、TLB感知调度、工作集预测和IOMMU干扰等词组。结果只能帮助找到近邻，不能证明穷尽文献；没有搜到同名方案不构成空白。正文引用只采用论文原文或作者/机构来源。

## 4. 当前方案为什么未过预审

| 审查项 | A：页感知提交 | B：配置选择 |
|---|---|---|

| 真实需求 | 当前是受控iDMA微基准，尚无选定应用的真实描述符/释放/复用轨迹 | 同样缺能说明为什么需要该选择的具体工作流 |
| 可证伪的新预测 | 尚未写出在何条件下、因何原因，页信息会比已调好的p1..p6及局部性普通规则更有用 | PN退化已有现象，但归因与未见条件预测尚未成立 |
| 净收益证据 | 旧p5没有胜过强基线；新A没有结果 | 172是功能验收和可分析旧样本，不能当新规则的留出验证 |
| 本轮决定 | 保留候选，暂不进入控制器实现 | 保留支撑分析，暂不作为已成立的独立创新 |

不能以“另加一个输入”代替上述论证：页标签很可能只是更贵的miss代理；静态已知页数可能只是普通工作集阈值。若没有改变决定或没有净用途，增加信息仍无贡献。反过来，控制位置不同不是零价值；若独立设备的合法顺序、描述符可见范围、控制时延等真实限制确实使既有方法失效，那么解决该限制可以有增量价值。目前这只是条件判断，尚未有相应场景/机制证据。

## 5. 进入后续工作的条件

先完成一张具体差异说明，以下四项具备才进入最低成本概念验证；不以一份新RTL或大矩阵先行替代立题。

1. **具体工作流和真实限制。** 给出任务释放、合法提交/完成顺序、源/目的页复用、IOMMU实际翻译路径及允许控制的位置。不能为了题目人为禁止强基线使用同等可用信息。
2. **最强前作在该条件下哪里不够。** 写到具体假设/动作与失败原因，而不是“GPU不是DMA”“RISC-V没人做”。若简单移植TCWS式页复用调度或已有反馈就足够，则不做复杂新机制。
3. **一条明确差异和可推翻预测。** 定义新增信息何时可得、预计怎样改变哪一次准入/配置决定、哪个相近条件应当无收益。可以先给纸面推演或已有轨迹分析，不要求先做大规模RTL。
4. **公平比较与停止条件。** 沿用适用的p1..p6、fixedgap、页/局部性普通规则，以及可适用的大页/回收/预取。计入控制等待、CPU/硬件成本、后台积压。若新信息没有带来强基线之外的用途，停止该机制；不为旧p5改条件找正结果。

可保留的提问是：“在一个已证实存在的DMA工作流中，源端可得的页复用信息能否补上已有反馈与局部性调度共同缺失的某个决策依据？”目前该句仍缺具体工作流及缺失依据，**不是已经找到的创新点**。也不预先将A限定成只能批次级控制；时间尺度由问题决定。

因此当前下一项仍是研究问题与证据收敛，暂停将A列为实现首选的旧安排。性能主线不变，不自动转安全、重做限速、续跑旧formal60或开始新BIT。创新预审通过后只能称“值得验证”，不能提前保证结果或发表。

## 6. 用户要求继续后的定向收窄

### 新补核的直接前作

[mNPUsim，IISWC 2023 作者全文](https://myshlee417.github.io/files/mnpusim_iiswc_2023.pdf)已在多 NPU 模型中研究 DMA 突发、搬运与计算重叠，以及 DRAM、PTW、TLB 的组合共享。§3.1 纳入 RAW 依赖和执行延迟；§4.1.3 的动态共享按先到先服务；§4.3–4.4 比较静态带宽/PTW份额与共享。因此“有突发、有依赖、多资源共同影响公平性”都不能再当作缺口。它没有在所核实验中评价我们设想的源端页感知控制，但这一点不能推出其它前作没有。其 NPU/IOMMU 配置是研究模型，不能外推所有现售 NPU。

[NeuMMU，2019 作者稿](https://arxiv.org/pdf/1911.06859)进一步直接讨论了局部性与并行性的取舍：§III-C（PDF第6–7页）指出降低 DMA 翻译突发可能损失内存并行度和带宽利用；§IV 采用请求合并、更多 PTW 和翻译路径寄存器。§IV-B 将跨加速器 QoS 资源分配留作后续研究。**这仅是该文范围，不代表2026年仍无人解决；MASK、DWS、mNPUsim及后续工作必须一起比较。** “GPU方法不适合NPU”或“限速会损失并行性”已经有直接前史。

DWS原文引言及“Impact of stealing on TLB”还直接说明 walker 份额会影响完成 walk 和 TLB 填充份额。因此 B 不能仅凭发现“服务与容量会相互影响”立题。它的 walker 窃取与本平台 N 的另一 bank 命中提前服务仍是不同动作。

### 两个收窄问题，均未认定创新

| 项目 | A1：翻译局部性与消费者等待的取舍 | B1：固定容量保护与命中提前服务的组合边界 |
|---|---|---|
| 具体问题 | 两路搬运—计算交替时，局部性更好的搬运是否反而可以晚发；局部性差的搬运是否会让消费者立即空等？ | 开启 N 后，P 对双方完成时间的边际影响为何可能变化，能否预测什么时候值得加 P？ |
| 真实场景证据 | mNPUsim/NeuMMU支持分块搬运与计算重叠的场景动机；本平台尚无相应应用轨迹或消费者时间线 | 已有172中PN/N随条件变化的旧观测；仍是微基准，尚无普适解释或应用级证据 |
| 最强反对意见 | 期限优先、计算 slack 配合普通限流、TCWS式局部性规则或旧p1..p6可能已经足够；增加两个特征不自动产生新机制 | KPart已有容量/带宽联合选择，DWS已有walker份额对TLB份额的影响；一般排队模型也可能充分解释 |
| 尚未解决的约束 | 消费者何时需要数据是否可知、前视范围、合法顺序与可控制的位置尚无工作流证据，不能人为制造限制 | 共享替换历史、正常lookup与快速命中服务、数据背压、完成驱动供给各自的作用尚未分开；PLRU或实现缺陷尚未排除 |
| 可证伪假设 | 在同等信息/代价下，纯局部性或纯进度规则在某个具体阶段作错决定；页特征与消费者需求的联系能修正它。**尚未给出胜过普通组合规则的实例** | N改变一次额外miss对另一流造成等待的路径，进而改变P的净用途。**这是待核路径假设，不是PN退化的已知根因** |
| 第一份必要证据 | 一条真实或可信轨迹，指出哪一次决定错、为何最强普通规则改不好；消费者 slack 本身可被普通调度使用，不能只给候选 | 一份由源码路径和已有原记录支持的因果说明：在哪个状态/握手多等了什么，既有容量/排队模型能否解释；缺信息时明确缺口 |
| 停止条件 | 普通期限/slack/局部性组合已解决，或工作流没有所设限制，就停止新增控制器 | 只剩本实现bug、常识性的容量代价或无法预测新条件，就作为工程分析收尾，不包装论文 |

**当前取舍：A1继续暂缓机制实现；B1保留为利用已有证据的小范围归因候选，不认定其更有新意。** B1的优势只是已有现象可查，降低下一次判断成本。不能因A困难就把B直接升级成论文主线，也不为B先重编BIT。

若后续开展受控比较，固定的是逻辑工作、地址/权限语义、合法释放规则、硬件资源和公平的测量边界；miss、PTW负载、实际吞吐及因完成速度变化产生的供给节奏是可能的中介/结果，不能强行相等。对于现有完成驱动源，需要明确这个反馈路径；若另需开放到达实验，须单独定义，不能把二者混为一谈。新采留出验证在概念假设成立后进行，不能要求“尚未允许概念验证前就已经取得完整收益”。
