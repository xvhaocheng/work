# 多 DMA 共享 IOMMU 研究收敛计划

当前计划总入口为[研究计划](../../研究计划.md)。本篇保留五篇核心前作、详细场景和此前裁决；当前工作顺序与验收以总入口及[当前状态](../../CURRENT_STATUS.md)为准。

2026年10月10日。目标是在现有平台上选定一个有证据支持、能被小实验推翻的机制问题，再决定是否值得做原型。采用截图中的顺序：核心前作的假设与边界、实际失效条件、最小改动、独立质疑、自身平台验证。

**本轮收敛为一条判别主线、一条有条件备选。主线先查翻译放行与 DMA 完成进度的失配；备选查阶段变化下现有反馈控制遗漏了什么。** 这是研究问题与投入顺序的选择，不代表已经发现新机制。模型、RTL、Linux、编译和上板本轮均未启动。

## 一 研究范围固定在哪里

研究对象沿用原始路径：多个 DMA 搬运各自数据，经共享 IOMMU 和共享存储系统。最小场景先用 V 与 A 两路，源与目的明确、映射稳定、权限正常、4 KiB 对齐 COPY；平台可以有四路 DMA，但首轮不由此假设四个 walker 或四个可调度翻译槽。

V 的完成延迟与 A 的有效进度必须同时评价。工作负载需写清任务何时就绪、提交依赖、数据量与结束条件。合法的参数化微基准可以作为起点，不能称为已经部署的应用。

本轮不增加共享源数据、必须晚到、可互换目的地址等语义。原来的 p5 固定 A8、共享载荷与在途加入、L-M/L-W、裸 walker continuation 保留历史记录，不改名重启。需要新语义时另写需求证据，不借原始实验为它背书。

## 三 三个边界如何取舍

| 方向 | 已有证据 | 缺少的决定性事实 | 本轮处理 |
|---|---|---|---|
| A 翻译放行与完成进度失配 | 受控 E3 有等待传播；隔离替换历史后 P/PN miss 数相同但完成时间不同；行为模型中改变返回策略会改变结果 | 在公平、合法、从原始起点开始的工作流中，具体哪个状态让完整简单控制作错决定；这个差异是否超出已有排队/优先级解释 | **主线的一次短期判别机会。** 理由是已有现象可查，下一次判断成本较低，不能因此认定创新概率更高。 |
| B 阶段变化中的保护与后台进度 | 固定 A8 的 p5 负结果不能推出所有阶段都无收益 | 一条有依据的阶段轨迹；旧反馈和廉价阶段选择器仍遗漏什么信息；观察与切换成本后是否有净收益 | **备选，暂不建模。** 必须先取得合法阶段与具体错误决策，不能只把固定 A8 换成几组页数。 |
| C 远端 miss 下的缓冲与放置 | 原毕业论文有远端延迟与拷贝路径基础；IOTLB Wall、rIOMMU 等有直接工作 | 哪项实际约束使大页、复用、缩小活跃集合或已知软件方法不足 | **本轮关闭。** 现有材料未形成更窄需求；不追加布局/迁移工程。 |

独立审查倾向先 B，理由是 A 可能只剩普通排队解释。root 选择先给 A 一个短关口，因为 B 的真实阶段轨迹与遗漏信息还未建立；同时接受审查提出的反馈、切换成本和对照冻结要求。排序基于下一次判别成本，不是模型投票。

## 四 主线必须先填完整的一张卡

拟检验的问题是：**在容量已受保护、并行度有限的共享 IOMMU 中，控制器是否会因没有区分已翻译但尚未完成的搬运状态，而在某个实际决策点放行错误的请求，损失 V/A 联合表现？**

这是待证伪假设。“看完成进度”“减少队列占用”都已有前史，不能作为答案本身。进入小模型前，卡片必须具体填出：

1. 哪个正常 COPY 序列进入该状态，地址、释放依赖和真实 R/W/B 如何完成。
2. 已有具体策略在第几个合法决策点选择了什么；为什么现有信息/动作导致这一选择。
3. 候选增加哪个可观测状态或合法动作，在什么条件下改选；给出确定的伪代码、更新与回退。
4. 一个相邻条件，预测收益消失或反转；不能只找赢的点。
5. 相对旧 p5、PTE 进展补额度、普通有限队列 credit、owner/完成优先的**具体新差异**。若规则相同，直接引用旧结果，不重测。

当前没有被接受的卡片满足以上五项，因此本计划没有给算法起新名字，也没有宣布立题通过。不要求先证明对所有负载有优势；有可信的可达差异假设，就允许最小模型。若第一个工作日仍只能写“PN 慢了，所以需要新控制”，主线关口失败，不启动新的诊断工程。

## 五 对照和评价口径先固定

### 主线对照

| 对照 | 固定规则 | 必须保留的能力与成本 |
|---|---|---|
| A0 现有结构 | 复用 S/P/N/PN；首轮容量按已有 16 项、P 为 2/14，不先调分区救候选 | 同一替换历史处理、实际在途额度、正常权限与真实数据完成；不把 8 个请求头当成 8 路翻译。 |
| A1 普通服务调度 | 保持已承诺响应稳定和同 ID 次序，在合法选择点先服务最老待办 PTE；数据流按已有公平顺序 | 不能把行为模型队列重排称为实板 MIG 实现。若这种普通控制已覆盖目标，结束相应性能主张。 |
| A2 普通流量控制 | 固定发出额度、固定 gap，以及从已有 p1–p6 中按预定校准规则选出的反馈控制 | gap 是完成后等待，额度是未完成请求上限，二者分开；旧 p1–p5 已用 V 完成量调预算，p6 已反馈调 gap。没有现成接口的上限控制需付接口和状态成本。 |

A0–A2 是筛选用的独立普通控制，不等于完整复现 MASK。若候选跨过这一步，必须补一份最近前作的机制映射：哪些 MASK 组件与本问题有关、如何迁移、缺哪些输入、付什么资源。不能凭击败单项 PTE 优先就宣称击败 MASK。若候选依赖已知组完成信息，同组完成优先、提前准备必要翻译也是直接强对照。

固定额度只枚举接口核实后合法的 1/2/4/8 上限；不得将超出实际配置的档位当现成能力。反馈参数从已有配置与校准条件选取并保存，不重新进行大规模寻优。对照清单须记录输入、状态、动作、窗口/步长/阈值/初态、资源和选择依据；**这些数值冻结是后续首个交付，本轮没有声称已经选好最优参数。**

比较时允许对照使用同等可得信息。若把候选整套新规则移植到普通模块，应标为等价实现或消融；逐场景事后最优仅作为离线上界。新发现的必要强对照可以加入，但要说明原因，并对双方在同一口径下重判。

### 固定工作和时间

- 先复用已有 4 KiB COPY、V/A 各 64 次的最小完整工作量。V 重用一对源/目的页；A 从已支持的页环配置选择。起点包括双方预热、就绪和排空状态，不让对照继承候选制造的堵塞。
- 对外部到达，固定任务就绪序列；对完成驱动任务，固定依赖程序与计算间隔，重新执行。不能强制两种方案拥有同一接受时刻，也不能用原执行的完成时刻冒充新方案的输入。
- 原合成 CPU 为完成驱动流，运行时间变化会改变请求数量。先无该背景或使用明确有限任务作局部干预；有背景的端到端比较执行同一程序并报告实际工作，不能把不同总量偷偷当作同一固定流量。局部回放不能替代执行驱动结论。
- 所有准入等待计入从逻辑就绪到真实完成的时间；包括 WRITE/B、描述符及控制等待。不能从候选开始放行时才计时。

主图为固定任务的 **V 完成时间—A 完成时间** 权衡，同时报告总完成时间、有效总吞吐、各自相对单独运行的 slowdown。服务上限必须让 A 最终完成；不以饿死 A 换取 V 改善。若另用固定窗口评价，窗口对所有方法相同，报告双方有效完成字节。miss、PTE 等待与占用积分只解释机制。

结果既要超过测量不确定性，也要有值得付出成本的效果；不把任意一个百分比当作创新门槛。尾延迟需要足够的作业样本和正确释放点，不能从三个窗口均值推出来。

## 六 八组以内的决定性场景

表中是问题组，不是八个单次运行。只运行能改变裁决的对照组合，先复用相同输入的已有结果，不做所有参数的笛卡尔积。具体值、期望和所用版本须在运行前登记。

| 组 | 只改变的关键条件 | 要判什么 |
|---|---|---|
| M1 最小正例候选 | 已有固定目的 COPY 中，出现卡片写明的具体放行选择 | 新规则与 A1/A2 是否真正作出不同的合法选择；没有这一点不运行后续组。 |
| M2 相邻阴性 | 相同逻辑任务，翻译已热或下游不拥塞 | 候选应失去优势或退回普通路径；若仍报告大收益，先查口径。 |
| M3 远端代价 | 保持任务与资源，只改变已支持的页表附加延迟 | 收益是否随事先预测的翻译关键性变化；不能混入不同数据延迟。 |
| M4 返回服务 | 同容量和单端口服务预算下，比较允许的 PTE 优先/跨 ID 服务 | 普通服务调度是否已经消除缺口；不能免费多一个物理端口。 |
| M5 已有并行度 | 从实际资源出发比较合法在途额度及普通控制 | 候选是否只赢了被人为限制的基线；不能把原生资源扣掉再当创新补回。 |
| M6 背景与供给 | 使用定义清楚的背景程序，区分无背景干预与有背景执行 | 排除原 CPU/供给混杂；判断局部差异是否仍影响完整任务。 |
| H1 留出条件 | 冻结规则后改变合法传输方向或 V/A 角色 | 检验是否只记住原场景；不要同时改多个因素。 |
| H2 留出条件 | 冻结规则后改变 COPY 长度或就绪间隔，二选一预先登记 | 检验对未参与选择条件的预测；失败后不得用同组继续调参冒充留出。 |

M1–M6 最多六组；没有差异就不运行 H1/H2。现有模型已回答的组直接引用。准备队列、选择器、tag、结果路由、返回缓冲、端口、比较器/关键路径和控制延迟都要列入成本；早期允许带上下界的估算，不能把 payload 字数当面积。协议错误、超容量或无法处理背压/权限失败的结果不参与性能比较。

备选 B 若被激活，优先替换尚未运行的场景槽，整个首轮仍控制在八组；不在主线失败后自动叠加另一套大矩阵。

## 七 备选的单独准入条件

B 只在同一合法工作流有阶段变化、且能指出现有反馈实际作错的决定时激活。阶段可以来自有明确动机的工作流模型，不要求先移植完整应用，但不能为候选编造只有它能知道的阶段标记。

三个固定对照是：校准后不变的静态配置、已有 p1–p6 中选定的反馈状态机、独立廉价阶段选择器。第三种可按上一窗口 miss/request 比及双阈值，在两个预定配置间切换；窗口、阈值、滞回、初态和成本在候选评价前冻结。如果应用原本提供阶段标记，各方都能使用，还要比较直接按标记切换。

当前模式配置要求 quiet，且合法配置会产生 clear；若切 S/P/N/PN，就必须计排空、配置、冷缓存及重热成本。若可恢复损失的乐观上界已小于最低转换成本，立即停止。固定完整阶段内容，只改变持续时间或次序作为相邻反例。不能先造无停顿热切换 RTL 来救立题。
