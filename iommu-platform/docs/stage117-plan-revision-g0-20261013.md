来源与接口的决定性边界如下：

- 多通道可服务同一 virtqueue，但原三帧使用同一 MAC/flow_id；组0={包1,包2}、组1={包3}是受控 dispatch grouping，不是两条原生流，也没有自然并发到达记录。
- 原来源逐包完成/前缀发布可与消费者重叠。当前适配等待全局 quiet 后才发布和消费，删除了这项因果依赖；原生逐包消费时延/流式吞吐投影不适用。有限阶段的硬件完整缓冲就绪与排空可以比较，应用时间未建模。
- DEFAULT 前端每引擎只允许一笔公开未完成 job，FIFO8 不等于可公开预排四笔。旧请求被 FIFO 实际捕获后，可在 WAIT 中准备下一笔 SRC/DST/NUM_BYTES；下一 NEXT 只在当前公开 DONE 匹配后触发。两种对照使用相同合法规则，控制只读公开寄存器，调试信号用于事后核验。
- 保留实际 DID10/11；两个 DDT 条目相同权限/context，共用非等值 Sv39 2MiB 叶与12KiB页表/设备表。16KiB数据池、原布局、首次正常使用与阶段内驻留不变，没有每copy flush、小页、私有隔离或新期限。
