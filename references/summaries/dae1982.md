# Decoupled Access/Execute Computer Architectures

稳定ID：`dae1982` · 类型：`research_paper` · 主题：`data-lifecycle`

作者：unknown；年份：1982；出处：ISCA 1982。

阅读等级：**局部已核（保留原有核读范围）**。本轮是资料归档，不新增人读标记或复现实验结论。

问题：处理器-内存通信时间成为性能约束，虚拟内存/保护检查加剧（`dae1982.txt:11-24`）。

机制／已存认识：A-processor 负责地址计算与访存，E-processor 负责执行；AEQ/EAQ 队列；store 一旦算出地址即发，WAQ 存地址等数据（`dae1982.txt:117-151`）；分支队列 EABQ/AEBQ（`dae1982.txt:226-238`）；队列用寄存器堆环形缓冲实现（`dae1982.txt:295-304`）。

支持边界：既有已存全文与逐篇笔记；本轮不重审评价。

限制：未复现论文实验；仅存全文不等于全文精读。；这不是实测硬件，也无现代多核/IOMMU；不能拿 1.7× 直接外推到任何现代系统。

与研究关系：本条用于对应主题的前作/语义边界；是否当前采用须回到总计划。

相邻资料：数据搬运、资源组织与动态内存近邻，历史收录不代表当前采用。
