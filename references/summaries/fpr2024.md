# Skip TLB flushes for reused pages within mmap’s

稳定ID：`fpr2024` · 类型：`preprint` · 主题：`lifecycle`

作者：Frederic Schimmelpfennig; André Brinkmann; Hossein Asadi; Reza Salkhordeh；年份：2024；出处：arXiv preprint (arXiv:2409.10946v1 [cs.OS])。

阅读等级：**局部已核（保留原有核读范围）**。本轮是资料归档，不新增人读标记或复现实验结论。

问题：unknown（既有JSON卡没有独立问题字段；已存机制、假设和原文证据保留如下，不能由题名补写）。

机制／已存认识：FPR 给物理页维护 recycling context ID；mmap/munmap 与 kswapd eviction 中若页仍被同一 context 回收，则跳过 TLB shootdown；页离开 context 到别的进程时才 shootdown，并用虚拟地址迭代避免 ABA。

支持边界：原记录的全文证据提取；root只抽核部分关键原文，未逐篇重审或复现。

条件：页可能被同一进程/用户 recycling context 重用；可用 MAP_FPR opt-in 标志和 per-page tracking metadata 跟踪 recycling；程序不会依赖 munmap 后立即 segfault 来调试；否则 FPR 会保留 stale 访问；kswapd 批量 evict 可在低 watermark 触发一次 shootdown

限制：不优化匿名 mmap/munmap malloc/free；虚拟化支持留未来工作；程序有 segfault 时可访问 stale 数据，必须谨慎开启；kswapd 回收路径需要特殊批量处理；不涉及设备 DMA、IOMMU、SVA

与研究关系：本条用于对应主题的前作/语义边界；是否当前采用须回到总计划。
