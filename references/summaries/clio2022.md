# Clio: A Hardware-Software Co-Designed Disaggregated Memory System

稳定ID：`clio2022` · 类型：`research_paper` · 主题：`accelerators`

作者：Zhiyuan Guo; Yizhou Shan; Xuhao Luo; Yutong Huang; Yiying Zhang；年份：2022；出处：ASPLOS '22。

阅读等级：**既有worker全文提取；非root逐篇精读**。本轮是资料归档，不新增人读标记或复现实验结论。

问题：unknown（既有JSON卡没有独立问题字段；已存机制、假设和原文证据保留如下，不能由题名补写）。

机制／已存认识：CBoard MN 硬件 fast path 做 VA→PA、permission checking、hardware page fault；flat overflow-free hash page table，TLB，async PA buffer；CN CLib 管 ordering/retry/congestion；MN 尽量无状态。

支持边界：原记录的全文证据提取；root只抽核部分关键原文，未逐篇重审或复现。

条件：当前应用使用 explicit ralloc/rread/rwrite API；每进程有 RAS，global PID 由 Clio 分配；page table 固定 DRAM，默认 4MB 大页；fast path page fault 3 cycles；无自动 cache coherence；安全依赖 PID authentic；无 built-in failure handling

限制：当前接口非透明；无自动 coherence；TLB shared across processes，无 per-connection bandwidth limit；failure handling 未做；fixed VA 不能保证，mmap(MAP_FIXED) 需 CN-local memory；migration pause 请求，1GB 1.3s（10Gbps 实验板）；FPGA 原型频率低，ASIC 投影非实测

与研究关系：本条用于对应主题的前作/语义边界；是否当前采用须回到总计划。

相邻资料：[deact2021](deact2021.md)：两者都做系统级/设备侧翻译与权限，但 DeACT 是 FAM node PA→FAM PA + STU，Clio 是 MN 硬件 VA→PA + RAS。；[dtl2023](dtl2023.md)：Clio 翻译 VA→PA，DTL 翻译 HPA→DPA；都利用 disaggregated memory，但 Clio 是计算+内存节点 co-design，DTL 是 CXL controller 内部翻译。
