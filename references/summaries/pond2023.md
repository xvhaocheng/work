# Pond: CXL-Based Memory Pooling Systems for Cloud Platforms

稳定ID：`pond2023` · 类型：`research_paper` · 主题：`lifecycle`

作者：Huaicheng Li; Daniel S. Berger; Lisa Hsu; Daniel Ernst; Pantea Zardoshti; Stanko Novakovic; Monish Shah; Samir Rajadnya; Scott Lee; Ishwar Agarwal; Mark D. Hill; Marcus Fontoura; Ricardo Bianchini；年份：2023；出处：ASPLOS ’23, March 25–29, 2023, Vancouver, BC, Canada, Volume 2。

阅读等级：**既有worker全文提取；非root逐篇精读**。本轮是资料归档，不新增人读标记或复现实验结论。

问题：unknown（既有JSON卡没有独立问题字段；已存机制、假设和原文证据保留如下，不能由题名补写）。

机制／已存认识：CXL池 + EMC 1GB slice ownership + zNUMA + ML预测latency-insensitive/untouched memory + QoS monitor；资源池化不等于共享地址翻译。

支持边界：原记录的全文证据提取；root只抽核部分关键原文，未逐篇重审或复现。

条件：CXL.mem load/store，无page fault/DMA；VM静态preallocation兼容虚拟化加速；EMC permission table按host id/slice owner；zNUMA映射为无核NUMA节点；ML预测可接受误预测并由QoS缓解

限制：依赖ML预测和QoS monitor；误预测只能缓解部分；ATS/PRI设备尚不广泛；vIOMMU需guest改动且有开销；hosts有separate coherency domains，池内存显式移动，不是共享一致映射；slice offlining慢，需异步release；未真实CXL硬件，使用emulation layer；未覆盖IOMMU/SVA、远端PTW

与研究关系：本条用于对应主题的前作/语义边界；是否当前采用须回到总计划。
