# DiDi: Mitigating The Performance Impact of TLB Shootdowns Using A Shared TLB Directory

稳定ID：`didi2011` · 类型：`research_paper` · 主题：`lifecycle`

作者：Carlos Villavieja; Vasileios Karakostas; Lluis Vilanova; Yoav Etsion; Alex Ramirez; Avi Mendelson; Nacho Navarro; Adrián Cristal; Osman S. Unsal；年份：2011；出处：PACT 2011。

阅读等级：**既有worker全文提取；非root逐篇精读**。本轮是资料归档，不新增人读标记或复现实验结论。

问题：unknown（既有JSON卡没有独立问题字段；已存机制、假设和原文证据保留如下，不能由题名补写）。

机制／已存认识：共享 inclusive 二级 TLB directory 跟踪翻译持有者，PTLBI 非中断式远端 invalidation，避免 IPI 和 false positive。

支持边界：原记录的全文证据提取；root只抽核部分关键原文，未逐篇重审或复现。

条件：per-core TLB + shared DiDi；inclusive directory；ASID 标识地址空间；PTLBI 可注入 LSQ memory barrier；32-256 核模型

限制：centralized DiDi 的 scalability 受质疑；ASID 位数有限；大页需 reset 对应 DiDi bits；PTLBI 上限约 off-chip 往返；不处理设备共享权限
