# CoLT: Coalesced Large-Reach TLBs

稳定ID：`colt2012` · 类型：`research_paper` · 主题：`foundations`

作者：Binh Pham; Viswanathan Vaidyanathan; Aamer Jaleel; Abhishek Bhattacharjee；年份：2012；出处：2012 IEEE/ACM 45th Annual International Symposium on Microarchitecture (MICRO)。

阅读等级：**既有worker全文提取；非root逐篇精读**。本轮是资料归档，不新增人读标记或复现实验结论。

问题：unknown（既有JSON卡没有独立问题字段；已存机制、假设和原文证据保留如下，不能由题名补写）。

机制／已存认识：在 TLB miss 填充路径上把“虚拟连续且物理连续”的多条翻译合并进单个 TLB 条目，利用 OS buddy allocator、内存压缩和 THS 自然产生的数十页中间连续性；CoLT-SA 改 set index 位在组相联 TLB 合并，CoLT-FA 在全相联超页 TLB 合并（单条 64B cache line 最多 8 条翻译、5-bit 长度字段最多 32 页），CoLT-All 用阈值分流并允许条目同时驻留两类 TLB。

支持边界：原记录的全文证据提取；root只抽核部分关键原文，未逐篇重审或复现。

条件：连续翻译必须在虚拟和物理两侧同时连续（consecutive virtual pages → consecutive physical page frames），不要求对齐（L91–L106）。；被合并的连续翻译必须共享同一组 page attributes 和 flags，否则不能合并（L378–L390）。；只在 TLB miss 时合并，不投机、不预取、不新增结构；合并逻辑在 fill 路径，不影响 lookup 时序（L236–L248、L313–L333）。；合并受 64B LLC cache line 与 set index 位限制，实践中最多合并 8 条翻译（L291–L300）。；CoLT-FA/CoLT-All 把全相联 TLB 从 16 项保守降为 8 项，以抵消更复杂 lookup 的时序影响（L336–L352）。；替换采用标准 LRU；合并项共用一组 attribute bits；失效时整条合并项 flush（L301–L312）。

限制：无硬件原型；CoLT 性能来自 trace-based miss rate + CMP$im 性能插值，不是硅后测量。；CMP$im 不维护虚拟→物理翻译，只跟踪已分配虚拟页并通过 miss rate 插值；作者说明该插值保守，没有计入 TLB miss 的指令 replay（L499–L510）。；评估基于 2012 年单机 Linux/Intel i7 与当时 TLB 组织，未覆盖虚拟化 ASID、多设备、IOMMU/SVA/PASID（L412–L419、L459–L485）。；连续性存在不等于合并有效：合并项必须在时间上被邻近使用，否则会被 evict；Tigr 虽有 50+ 页平均连续性，但只消除 10% miss（L758–L768）。；每条合并项只有一组 attribute bits，不支持逐翻译独立属性；失效 flush 整条合并项，会丢失未受影响页的信息（L304–L312、L378–L390）。；没有远端 PTW、队列、尾延迟、翻译结构容量的定量结果；性能与 miss 消减均为平均值。
