# Observations and Opportunities in Architecting Shared Virtual Memory for Heterogeneous Systems

稳定ID：`svm2016` · 类型：`research_paper` · 主题：`accelerators`

作者：Jan Vesely; Arkaprava Basu; Mark Oskin; Gabriel H. Loh; Abhishek Bhattacharjee；年份：2016；出处：2016 IEEE International Symposium on Performance Analysis of Systems and Software (ISPASS)。

阅读等级：**既有worker全文提取；非root逐篇精读**。本轮是资料归档，不新增人读标记或复现实验结论。

问题：unknown（既有JSON卡没有独立问题字段；已存机制、假设和原文证据保留如下，不能由题名补写）。

机制／已存认识：在AMD Kaveri APU上实测CPU-GPU共享虚拟内存：GPU TLB miss经ATS到IOMMU，页错误经PPR队列，TLB shootdown经IOMMU，并量化延迟与并发。

支持边界：原记录的全文证据提取；root只抽核部分关键原文，未逐篇重审或复现。

条件：AMD A10-7850K APU/Kaveri；HSA/KFD/Linux 4.0；PASID匹配页表基地址；GPU使用ATS可预取最多8个连续4KB页；应用数据驻留系统DRAM并使用SVA

限制：单一商用平台，第一代硬件；第二代APU仅初步观察；只测平均延迟，不测尾延迟分布；无新机制，主要是表征；未覆盖A/D位、页面迁移、device ID spoofing
