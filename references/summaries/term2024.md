# TeRM: Extending RDMA-Attached Memory with SSD

稳定ID：`term2024` · 类型：`research_paper` · 主题：`io`

作者：Zhe Yang; Qing Wang; Xiaojian Liao; Youyou Lu; Keji Huang; Jiwu Shu；年份：2024；出处：USENIX FAST 2024。

阅读等级：**既有worker全文提取；非root逐篇精读**。本轮是资料归档，不新增人读标记或复现实验结论。

问题：unknown（既有JSON卡没有独立问题字段；已存机制、假设和原文证据保留如下，不能由题名补写）。

机制／已存认识：用magic physical page把RNIC页表中无效虚拟页映射到预定义页，消除RNIC缺页；客户端识别magic pattern后RPC取缺失数据；tiering IO绕开CPU缺页；后台热点提升。

支持边界：原记录的全文证据提取；root只抽核部分关键原文，未逐篇重审或复现。

条件：服务端mmap SSD形成大于物理内存的虚拟内存，并注册TeRM MR。；tLib通过LD_PRELOAD覆盖libibverbs；修改Mellanox RNIC driver；客户端/服务端协作。；magic pattern覆盖整页字节，客户端按页划分和逐字节检测无效页；page bitmap可预判但可不准确。；热点提升在后台执行，不在关键路径；sample unit 1MB，周期1s。

限制：消除缺页后冻结数据放置；热点提升是后台补偿。；TeRM MR不适用于write request；写走RPC，部分写做read-modify-write并加锁。；magic pattern存在误报可能，靠低概率、动态magic和RPC重取保证正确。；依赖Mellanox RNIC driver和libibverbs覆盖；实现约6100行tLib加300行driver。；未覆盖多MNode、远端PTW、跨设备SVA、生产多租户p99.9 SLO和FPGA实现。

与研究关系：本条用于对应主题的前作/语义边界；是否当前采用须回到总计划。

相邻资料：[rdmaodp2021](rdmaodp2021.md)：TeRM在参考文献中引用rdmaodp2021，并据其说明ODP缺页开销问题。；[odrp2025](odrp2025.md)：TeRM把RNIC缺页异常onload到软件并维护RNIC页表；ODRP绕过ODP缺页，用RDMA WR链做远端交换页分配和管理。；[fastsafe2024](fastsafe2024.md)：两者都减少关键路径翻译异常开销，但TeRM针对RNIC/SSD，F&S针对IOMMU IOTLB/PTcache。
