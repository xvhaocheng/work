# Interference from GPU System Service Requests

稳定ID：`ssr2018` · 类型：`research_paper` · 主题：`io`

作者：Arkaprava Basu; Joseph L. Greathouse; Guru Venkataramani; Ján Veselý；年份：2018；出处：IISWC 2018。

阅读等级：**既有worker全文提取；非root逐篇精读**。本轮是资料归档，不新增人读标记或复现实验结论。

机制／已存认识：GPU 通过 page fault 等 SSR 请求 CPU/OS 服务，CPU 处理导致 CPU/GPU 相互干扰；用 QoS backpressure 限 CPU 开销。

支持边界：原记录的全文证据提取；root只抽核部分关键原文，未逐篇重审或复现。

条件：GPU 支持 shared virtual memory 和 page fault 等 SSR。；GPU 不能直接执行 OS 服务，必须由 host CPU 处理。；软缺页不访问磁盘；独立 CPU 与 GPU 工作负载。；QoS 假设加速器有 outstanding SSR 硬件上限，延迟服务可给 GPU 背压。

限制：单 AMD A10-7850K 集成 GPU；软缺页；Linux 4.0.0；未测多加速器。；全文无正式出版信息，year/venue null，status uncertain。；缓解措施不普遍有效；最佳组合仍 CPU 降 5-20%。；QoS 只保证 CPU，牺牲 GPU；需管理员设阈值；未做 GPU QoS。；未覆盖跨设备共享翻译、SVA/PASID、迁移、远端 PTW、多租户、尾延迟。；作者列表题名为Interference from Accelerator System Service Requests，本地稿题名为Interference from GPU System Service Requests；保留版本题名差异。
