# DRAM Translation Layer: Software-Transparent DRAM Power Savings for Disaggregated Memory

稳定ID：`dtl2023` · 类型：`research_paper` · 主题：`accelerators`

作者：Wenjing Jin; Wonsuk Jang; Haneul Park; Jongsung Lee; Soosung Kim; Jae W. Lee；年份：2023；出处：ISCA '23。

阅读等级：**既有worker全文提取；非root逐篇精读**。本轮是资料归档，不新增人读标记或复现实验结论。

问题：unknown（既有JSON卡没有独立问题字段；已存机制、假设和原文证据保留如下，不能由题名补写）。

机制／已存认识：在 CXL memory controller 内加 DTL，做 HPA→DPA segment translation 与 host-transparent page migration；用 rank-level power-down 和 hotness-aware self-refresh 节能。

支持边界：原记录的全文证据提取；root只抽核部分关键原文，未逐篇重审或复现。

条件：CXL/Gen-Z memory-semantic fabric；commodity DRAM 支持 MPSM/self-refresh；VM deallocation 可触发 consolidation；DTL 可信且不改变 host OS/MC；segment 默认 2MB，AU 2GB；不做 access control/security

限制：无 FPGA/ASIC 原型，CXL 延迟用 Quartz 模拟；不做安全/access control；hotness self-refresh 可能 ping-pong 或无法进入；8-rank 时 rank-level power-down 不适用；migration tail latency 未充分评估

与研究关系：本条用于对应主题的前作/语义边界；是否当前采用须回到总计划。

相邻资料：[deact2021](deact2021.md)：两者都在系统级/设备侧加翻译层，但 DeACT 是 node PA→FAM PA + access control，DTL 是 HPA→DPA + power migration。；[clio2022](clio2022.md)：Clio 在 MN 硬件做 VA→PA，DTL 在 CXL controller 做 HPA→DPA；两者都向设备侧下沉，但翻译平面不同。
