# EMT: An OS Framework for New Memory Translation Architectures

稳定ID：`emt2025` · 类型：`research_paper` · 主题：`foundations`

作者：Siyuan Chai; Jiyuan Zhang; Jongyul Kim; Alan Wang; Fan Chung; Jovan Stojkovic; Weiwei Jia; Dimitrios Skarlatos; Josep Torrellas; Tianyin Xu；年份：2025；出处：19th USENIX Symposium on Operating Systems Design and Implementation (OSDI '25)。

阅读等级：**局部已核（保留原有核读范围）**。本轮是资料归档，不新增人读标记或复现实验结论。

问题：unknown（既有JSON卡没有独立问题字段；已存机制、假设和原文证据保留如下，不能由题名补写）。

机制／已存认识：在 Linux 上抽象 translation object/database/service，用 MMU driver 实现 radix/ECPT/FPT 等翻译结构，保持架构无关代码可扩展。

支持边界：原记录的全文证据提取；root只抽核部分关键原文，未逐篇重审或复现。

条件：新翻译架构可由 MMU driver 实现基本函数；可定制函数保留硬件特定优化；ECPT/FPT 可在 QEMU 模拟 MMU 上评估；EMT 接口开销可忽略

限制：EMT 不改变物理页操作；只聚焦 CPU VA→PA translation；明确不面向 IOMMU DMA translation；只支持 native，虚拟化在 roadmap；ECPT 有 kECPT self-reference paradox、锁/稀疏地址空间问题

与研究关系：本条用于对应主题的前作/语义边界；是否当前采用须回到总计划。
