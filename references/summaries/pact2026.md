# PACT: A Criticality-First Design for Tiered Memory

条件：Intel CHA/TOR counters可用；AMD需IBS+Little's Law近似；20ms窗口内MLP稳定，可按访问频率比例分摊stall；PEBS默认1/400足够；PAC分布高度skew，需动态binning；Linux 5.15 + TPP模块，禁用NUMA hint fault scanning

限制：proportional attribution在同tier异构/多租户下可能稀释latency-sensitive页；默认只采slow-tier load，demotion依赖Linux (M)LRU；4KB PAC选中THP时迁移整个2MB页；未量化TLB shootdown；部分workload输给Soar/Colloid/NBT/Memtis；Soar离线profiling在部分场景更好；未覆盖IOMMU/SVA、远端PTW、多设备共享页表
