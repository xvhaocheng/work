# CVA6-RT: an Open-Source Time-Predictable RV64 Processor for Mixed-Criticality Systems

稳定ID：`cva6rt2026` · 类型：`preprint` · 主题：`foundations`

作者：Enrico Zelioli; Christopher Reinwardt; Nils Wistoff; Robert Balas; Alessandro Ottaviano; Luca Benini; Angelo Garofalo；年份：2026；出处：arXiv:2606.26177; RISC-V Summit Europe 2026 short manuscript。

阅读等级：**既有worker全文提取；非root逐篇精读**。本轮是资料归档，不新增人读标记或复现实验结论。

问题：unknown（既有JSON卡没有独立问题字段；已存机制、假设和原文证据保留如下，不能由题名补写）。

机制／已存认识：在 CVA6 核内加入可配置 TLB 分区与静态锁定、L1 cache/scratchpad 混合模式、增强 CLIC 和硬件上下文压栈，以降中断和地址翻译的延迟变异。

支持边界：原记录的全文证据提取；root只抽核部分关键原文，未逐篇重审或复现。

条件：任务被分配给不相交的 TLB partition，以避免替换驱逐干扰；特权软件通过 bitmap 选择 active partition，并配置静态锁定 TLB 条目；L1 cache ways 可动态配置为 cache 或 software-managed SPM；SPM 区域映射到 SoC 地址空间；使用增强 CLIC 与硬件辅助寄存器压栈；硬件可把寄存器 spill 到预定内存位置；面向 mixed-criticality/soft real-time 场景

限制：短文/预印本，评估只报告中断延迟；未说明是仿真、FPGA 还是流片实测；没有 IOMMU、设备 DMA、SVA、共享页表或多设备共享翻译评估；TLB 锁定为静态条目；未评估容量/置换灵活性代价；没有动态映射、迁移、失效或尾延迟实验；不能当 IOMMU 端到端实时保证，也不能当设备隔离证据；保存为公开短稿/预印本，不据Summit页脚宣称已通过正式论文审稿或端到端硬实时保证。

与研究关系：本条用于对应主题的前作/语义边界；是否当前采用须回到总计划。

相邻资料：[iotlb_bottleneck2010](iotlb_bottleneck2010.md)：CVA6-RT 是核内 TLB 资源分区/锁定，目标是实时可预测性；2010 是 IOMMU IOTLB 冲突/预取，目标是 DMA 吞吐；二者资源层级不同。；[m2ndp2024](m2ndp2024.md)：CVA6-RT 未涉及 CXL/设备侧共享翻译；不能把核内 TLB 分区等同于共享 IOMMU 或设备 ATC 保证。
