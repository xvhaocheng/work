# Utility-Based Cache Partitioning: A Low-Overhead, High-Performance, Runtime Mechanism to Partition Shared Caches

稳定ID：`ucp2006` · 类型：`research_paper` · 主题：`data-lifecycle`

作者：unknown；年份：2006；出处：MICRO 2006。

阅读等级：**局部已核（保留原有核读范围）**。本轮是资料归档，不新增人读标记或复现实验结论。

问题：多核共享 LLC 的 demand-based LRU 隐式分区，需求高不等于收益高。

机制／已存认识：UMON（ATD + hit counters）利用 LRU stack property 估计所有 way 数的 miss；DSS 采样 32 sets；Lookahead/greedy 分区；tag bit 实现 way partitioning（`papers/ucp2006.txt:100-118, 236-276, 338-370, 378-429`）。

支持边界：既有已存全文与逐篇笔记；本轮不重审评价。

限制：未复现论文实验；仅存全文不等于全文精读。；不能把 UCP 直接搬到 IOMMU IOTLB 或 DMA 共享；没有真实硬件、没有 multithreaded、没有安全/隔离语义；DSS 是静态采样；不能声称它解决了混合关键性或不可信设备。

与研究关系：本条用于对应主题的前作/语义边界；是否当前采用须回到总计划。

相邻资料：数据搬运、资源组织与动态内存近邻，历史收录不代表当前采用。
