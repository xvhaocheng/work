# Distributed Page Table: Harnessing Physical Memory as An Unbounded Hashed Page Table

稳定ID：`dpt2024` · 类型：`research_paper` · 主题：`foundations`

作者：Osang Kwon; Yongho Lee; Junhyeok Park; Sungbin Jang; Byungchul Tak; Seokin Hong；年份：2024；出处：2024 57th IEEE/ACM International Symposium on Microarchitecture (MICRO)。

阅读等级：**既有worker全文提取；非root逐篇精读**。本轮是资料归档，不新增人读标记或复现实验结论。

问题：unknown（既有JSON卡没有独立问题字段；已存机制、假设和原文证据保留如下，不能由题名补写）。

机制／已存认识：把物理内存当作无界哈希页表，用 Hash(VPN tag, PID) 直接定位 PTE 页，SOA/CVA/CPD 解决地址碰撞，DMT/DMC 缓存参数。

支持边界：原记录的全文证据提取；root只抽核部分关键原文，未逐篇重审或复现。

条件：PTE 页用哈希直接定位，地址碰撞可解决；PTE 页不可迁移；数据页可迁移但需 reverse map；CVA 依赖 OS 选择无碰撞虚拟地址区域；DMT/DMC/MMU 改动可接受

限制：高利用率下 CPD 更频繁，98% 利用率性能下降约 3.3% 并 TLB shootdown；PTE 页/non-migratable 页不能迁移；CVA 有 MAX CVA SIZE/CNT 限制，demand paging 适用性有限；主性能来自模拟，真机只验证分配机制；不涉及 IOMMU/SVA

与研究关系：本条用于对应主题的前作/语义边界；是否当前采用须回到总计划。
