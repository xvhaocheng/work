# Leveraging Chiplet-Locality for Efficient Memory Mapping in Multi-Chip Module GPUs

稳定ID：`clap2025` · 类型：`research_paper` · 主题：`multigpu`

作者：Junhyeok Park; Sungbin Jang; Osang Kwon; Yongho Lee; Seokin Hong；年份：2025；出处：58th IEEE/ACM International Symposium on Microarchitecture (MICRO ’25)。

阅读等级：**局部已核（保留原有核读范围）**。本轮是资料归档，不新增人读标记或复现实验结论。

问题：unknown（既有JSON卡没有独立问题字段；已存机制、假设和原文证据保留如下，不能由题名补写）。

机制／已存认识：利用GPU data structure的chiplet-locality，按数据结构选择合适页大小，把连续虚拟页映射到同一chiplet的连续物理帧，形成大页式区域并用TLB coalescing扩展TLB reach；默认避免页迁移。

支持边界：原记录的全文证据提取；root只抽核部分关键原文，未逐篇重审或复现。

条件：MCM GPU使用统一地址空间和单一GPU页表，page duplication不可用。；GPU driver可控制VA/PA映射并做预放置。；物理地址channel bits的高位可作为chiplet identifier。；PTE reserve bits可存allocation ID，GMMU内有Remote Tracker。；GPU workload存在稳定的chiplet-locality，PMM采样能代表后续访问。；硬件支持TLB coalescing或2MB promotion。

限制：主要基于GPGPU-Sim模拟和Verilog/28nm面积估计，缺少真实GPU全系统原型或FPGA原型。；默认不做page migration；对跨kernel复用且访问模式变化的数据结构无法重映射，CLAP+migration只是选择性扩展。；中间页大小通过连续页分组模拟，原生支持需改页表和GMMU；TLB coalescing增加L2 TLB面积。；小allocation或未完整映射的VA block退回OLP，PMM阈值20%为经验值。；未评估多租户、权限/PASID/SVA、尾延迟和真实部署。

与研究关系：本条用于对应主题的前作/语义边界；是否当前采用须回到总计划。
