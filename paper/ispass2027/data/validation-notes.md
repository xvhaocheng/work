# 已有结果的数据验证记录

## Material Passport

- 阶段：ARS experiment-agent / validate，限定在已有数据的统计解释和可复现提取。
- 输入：`source_manifest.json` 所列原始或已验收复核 JSON 与必要的历史身份/哈希回执。
- 输出：两份 CSV、稳定行索引、来源清单及机器验证回执。
- Verification Status：ANALYZED；数据提取已通过确定性重建。历史 FPGA/RTL 测量未重跑，不以本次重建声称硬件实验重新 VERIFIED。
- 权限：仅本目录的数据提取与复核；无新机制、实验、综合、烧写或加载。

## 实际执行与接受范围

已运行提取器，逐行解析源 JSON pointer 或显式计算表达式，检查唯一 `row_id`、数值/空值类型和源文件身份。随后运行 `--check`，要求所有生成文件逐字节一致，并检查每个输入文件仍与来源清单同哈希。

关键独立计算包括：E1 主矩阵的 80 个原始试次及时间/HPM 统计；自主 batch 的每条件硬件时间和在途重叠中位数；E3 真实触发配对的各剩余时间差及整次周期差；E2 全部 64 个原始探测统计与复核提取的一致性；P4M 各采集段的中位数、极值和 Type 7 四分位数；composition 两侧每例共同窗口及关键计数与 raw words 的一致性和 P/PN 成对比值；失效仿真的匹配 M0 分母。

这里的“通过”只表示本次数据来源、提取和指定计算核对通过；原始实验的验收范围、计数器语义和身份缺口仍沿用各轮原报告。全部计数与输出 SHA256 以 `validation.json` 为准，新增数据后不靠本页的旧计数验收。

## 统计解读

所有导出统计均为有限样本描述，不实施新的显著性检验、假设检验、多重比较或总体推断。`min/max` 是观察范围，P4M 的 `q1/q3` 是样本四分位数；它们都不是 95% 置信区间。各轮条件顺序按历史协议轮换，不能描述成随机抽样或独立同分布样本。仿真每配置一次的确定性值不提供硬件运行噪声或跨部署方差估计。

没有把缺测费用置零；未触发不等于观察到“相同暴露下零效果”；没有从同 miss 数推出同页序、相同服务时间或相同吞吐。软件、计数器、硬件请求阶段和完整任务各用本身的时间边界。
