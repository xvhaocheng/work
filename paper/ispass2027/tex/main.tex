\begin{abstract}
Shared I/O translation can delay a device even when its own address translations hit in the cache.\claim{R-E3} This paper characterizes a fixed open RISC-V input/output memory management unit on a field-programmable gate array (FPGA) with autonomous concurrent direct-memory-access traffic.\claim{M-IDENTITY} A zero-miss co-run control separates ordinary shared-path loss from the additional loss observed when the neighbor's translation working set grows.\claim{M-CONTROLS} Segmented observers locate waiting, and a bounded intervention on a named page-table-walk response traces waiting propagation to a neighboring request that subsequently hits.\claim{M-PATH}\claim{R-E3} A repaired baseline provides \BaselineTotalRuns{} board trials across direct wiring and an added-delay diagnostic configuration.\claim{M-BASELINE} The latter is a sensitivity experiment, rather than a measurement of pure page-table-walk cost.\claim{M-DS} Historical capacity and mitigation experiments expose distinct replacement effects and costs to the interfering stream; an invalidation-scope study is reported separately as simulation.\claim{R-CAPACITY}\claim{R-MITIGATION}\claim{R-INVALIDATION} Device-count scaling, workload-shape and page-size coverage, and request-latency distributions remain explicit gaps in this working draft.\claim{G-COVERAGE}
\end{abstract}
