# 切换与核查记录

- `current-status-before-submission-mode.md`是切换前根`CURRENT_STATUS.md`的原字节快照；其中相对链接仍以原工作区根为上下文，不改写历史正文。[当前状态](../../../CURRENT_STATUS.md)和[研究导航](../../../研究导航.md)提供可点击入口。
- `root-evidence-check.json`保存主会话直接从原始batch/path数据重算的关键数字，不把子agent汇总当作唯一证据。
- `document-validation.json`检查新交付链接和图表行映射；历史原字节快照按其原上下文处理。

硬件和构建身份、SD备份/返回验证、加载与每次原始数据各在`../board/`，不因文档存在声明实际运行完成。
